## 摘要
KellyBoost是一个单一的多输出XGBoost模型，其softmax输出即为投资组合：以y表示每项资产的持有期收益向量，训练损失为-log(1 + w y)，即负对数增长率，因此拟合模型是条件于特征的增长最优（Kelly）配置。该目标函数是精确的而非替代函数：我们推导了梯度、解析对角Hessian矩阵和完整Hessian矩阵的闭式表达式，通过有限差分验证，并提供了一个无依赖的参考引擎。

## Abstract
KellyBoost is a single multi-output XGBoost model whose softmax output is the portfolio: with y the vector of per-asset holding-period returns, the training loss is - log(1 + w y), the negative log growth rate, so the fitted model is the growth-optimal (Kelly) allocation conditioned on the features. The objective is exact rather than a surrogate: we derive the gradient, the analytic diagonal Hessian and the full Hessian in closed form, verify them by finite differences, and ship a dependency-free reference engine.

# 论文详细总结：KellyBoost——基于梯度提升树的增长最优投资组合构建

## 1. 核心问题与整体含义（研究动机与背景）

- **传统组合构建的“缝合”问题**：主流机器学习组合构建方法将“预测”与“决策”分离——先用模型预测收益（或分类最优资产），再交给优化器求解权重。这种两步流程存在三方面缺陷：
  1. 预测误差被优化器在关键方向放大；
  2. 期望收益是金融数据中最难估计的量；
  3. 两阶段目标不一致，改善第一阶段未必改善最终组合表现。
- **端到端学习的现状与空白**：端到端（决策聚焦）组合学习能直接以金融目标训练模型，但已有工作几乎全部依赖神经网络和反向传播。梯度提升决策树（GBDT）——表格数据与量化实践的常用模型——因无法通过反向传播训练，长期被排除在端到端框架之外，只能被迫使用代理目标（预测收益或分类）。
- **本文的核心贡献**：构建了将“增长最优（Kelly）目标”直接嵌入梯度提升树训练的完整公式——**KellyBoost**，使学习者类别（树模型）与训练目标（精确决策目标）不再是二选一的决策，同时不引入任何近似。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体框架
- 使用**单一多输出 XGBoost 模型**：每行输入特征产出 K 维 logit 向量，经 softmax 映射为 K 个资产的权重，满足仅做多、全额投资的单纯形约束。
- 训练损失为 **负对数增长率**：对每行持有期收益向量 y 和组合权重 w，损失为 `-log(1 + w^T y)`，样本均值即负样本对数增长率。最小化该损失等价于最大化财富的几何增长，因此拟合模型是条件于特征的增长最优（Kelly）配置。
- 该目标是**精确经济目标**而非代理，因此超参选择、评估均使用同一数量，消除代理度量缝隙。

### 2.2 精确梯度与 Hessian
- 对 logit `z_k`，梯度：
  ```
  g_k = σ_k(S - y_k) / (1 + S)
  ```
  其中 `σ_k = softmax(z)_k`，`S = w^T y` 为组合收益。
- 对角 Hessian：
  ```
  h_k = g_k(1 - 2σ_k) + g_k²
  ```
- 完整 Hessian（以 CRRA 效用 ϕ 给出一般形式）：
  ```
  H = ϕ''(S) a a^T + ϕ'(S)[diag(a) - σ a^T - a σ^T]
  a = [diag(σ) - σ σ^T] y
  ```
- 所有导数均通过中心有限差分验证（梯度相对容差 1e-5，Hessian 1e-3）。
- **非凸性处理**：损失在 z 上非凸，Hessian 可能为负，XGBoost 要求聚合 Hessian 为正，因此采用 `|h_k|`。作者说明这等价于 saddle-free Newton 的对角形式；并证明整流后每叶更新仍是下降步（方向不变，仅改变步长）。
- **风险偏好旋钮**：支持 CRRA 效用族 `ϕ_γ(S) = ((1+S)^(1-γ) - 1)/(γ - 1)`，γ→1 恢复对数损失；γ>1 可温和化 Kelly 策略，类似于分数 Kelly。

### 2.3 二阶提升与向量叶
- 树是向量值（每叶存 K 维向量），XGBoost 的 `multi_strategy = multi_output_tree`。
- 因 Hessian 对角化，第二轮展开按输出解耦：给定树结构后，叶值按坐标独立 Newton 步 `v_jk = -G_jk / (H_jk + λ)`。
- 分裂搜索为**联合评分**：候选分裂的增益需对所有 K 个输出求和，这意味着所有资产共享一个特征空间划分——一个对整体有用的机制变量（如曲线倒挂、波动率骤升）只需一次分裂即可服务全部输出，减少 K 倍参数。

### 2.4 部署：固定参数留一法集成
- 单棵树对训练集微小扰动极其敏感：删除一行（约 0.02% 数据）可能因分裂点几乎并列而大幅改变分配权重。
- 部署方案：拟合 K 个成员，第 s 个成员在“删除第 s 行”的数据上训练（种子即成员索引），最终取成员权重向量的平均（平均仍在单纯形上）。
- 与 bagging 不同，留一扰动极小，不改变有效容量，因此调参结果仍然有效；平均以 1/√K 速率向中心收敛，K=4 已足够且使结果确定性化。

### 2.5 特征选择作为选择的一部分
- 构建 7,871 列候选特征集（价格类：动量、回撤、均线比、z-score、波动率、偏度、峰度、Hurst 指数、百分位排名等；收益率类：变化、斜率、z-score 等；窗口分位数特征）。
- 特征列表被当作超参数，与模型超参联合搜索：先用 20 个根特征，再对每个候选特征做一次小拟合，按增益占比排序，取 top 300 构成池；再用随机局部搜索（超参扰动 + 增删特征）在开发段上优化选择得分。
- 所有方法使用相同的候选集、预算和搜索流程。

### 2.6 选择 vs 估计的严格分离
- **选择阶段**：仅在开发段（2003-02 至 2012-12）用清理后的 walk-forward 打分，测试块为每 11 行取单行，训练集剔除标签重叠的 h-1 行并设置 embargo；该分数只用于排名，不视为性能。
- **估计阶段**：在从未参与开发的评估段（2013-01 至 2026-07）做一次部署 walk-forward：每 21 个交易日决策一次，用展开窗口（只含尾部标签已实现的行）重拟合冻结参数下的留一集成；决策网格锚定在最后一个可决策行并向前计数，保证使用最新信息。

## 3. 实验设计

### 3.1 数据集
- **资产腿**：8 个可投资资产——成长股（VIGRX）、价值股（VIVAX）、长期国债（VUSTX）、国际股票（VGTSX）、能源股（VGENX）、黄金（GC=F）、白银（SI=F）和现金（13 周国库券利率）。
- **特征序列**：38 条公开数据，包括 S&P 500、VIX、4 条国债收益率、铜、8 个 SPDR 板块 ETF、美元指数、罗素 2000、纳斯达克、新兴市场、REITs、信用债、TIPS、天然气、SKEW 指数、农产品、日元等。
- **标签**：未来 20 个交易日简单收益；相邻行标签重叠 19 天，清理协议专门处理该重叠。
- 所有数据来自 Yahoo Finance 免费下载，原始快照提交在仓库，无需 API key，因果性由构造保证（只用当日收盘与回溯变换）。

### 3.2 对比方法（benchmark）
- **KellyBoost（本文）**：精确增长目标 + 多输出 XGBoost。
- **Two-stage predict-then-optimize**：LightGBM 回归预测每项资产 20 日收益，结合滚动协方差估计，求解二次展开的 plug-in Kelly 组合。
- **Multiclass surrogate**：LightGBM 多分类预测“最优资产类别”，类别概率直接作为组合权重。
- **MLP, same loss**：前馈网络（至多 2 隐藏层，Adam），以相同对数增长率损失 + softmax 头端到端训练。
- **MLP, surrogate loss**：相同网络，以 argmax 标签的交叉熵训练。
- **Unconditional Kelly**：固定单纯形权重，样本内最大化对数增长，每次决策重估计。
- **2×2 设计**：{提升树, MLP} × {增长目标, 分类代理}，在每类学习者内部固定其他条件，只换训练损失，从而隔离“损失”效应。

### 3.3 评估指标
- 主指标：每次 20 日决策的**实现对数增长率均值 log G**。
- 辅助指标：年化几何收益、年化波动率、日频超额 Sharpe、最大回撤。
- 成对差异用 **moving-block bootstrap** 计算 95% 区间（块长 21 天，5000 次）；2×2 损失效应用逐决策配对的 circular moving-block bootstrap（块长 6 决策，10000 次）。
- 主表为毛收益，另以实测换手率在 5/10/20 bps 单边成本下做敏感性检验。

## 6. 主要结论与发现

1. **增长目标胜过分类代理（核心主张）**：在 4 个 2×2 单元中（树×搜索、树×手建、MLP×搜索、MLP×手建），增长目标均获得更高的已部署对数增长率；池化的配对效应为每决策 +0.18（×100），在 20 bps 成本下升至 +0.25，且增长目标在每单元换手率更低，成本使差距扩大而非侵蚀。
2. **两阶段流水线在本机制中胜出**：因月度收益几乎不可预测，平方误差预测接近零，优化器输出温和多样化组合，起隐式正则作用。所有端到端学习者均落后于两阶段流水线（但无一成对差距通过 bootstrap 显著性检验）。
3. **精确 Hessian 是更好的优化器、更差的部署者**：在开发选择协议上精确 Hessian 得分 +4.19，常数 Hessian 仅 +1.43（高 3 倍）；但部署后常数 Hessian 因步长不足而隐式收缩 softmax 更均匀，反而表现更好（log G 0.67 vs 0.47）。作者解释：优化技能可转移，但“估计的全 Kelly 目标”不可转移；问题不在树、提升或导数推导，而在增长最优目标与估计误差的交互。
4. **特征搜索大幅提升选择分数，但部署收益按流水线分化**：两阶段流水线将搜索转化为部署收益（log G 从 0.38 升到 0.82）；端到端方法仅重新分配集中度，MLP 两个搜索清单甚至比手建表现更差。
5. **条件化资产配置确有价值**：KellyBoost 胜过无条件 Kelly（0.47 vs 0.42）。
6. **留一集成稳定权重但无增长增益**：只消除分裂点硬币翻转的脆弱性，K 从 1 到 16 的部署增长率在噪声内持平。
7. **对角 Hessian 足够**：在调优正则化下，叶级对角步与完整 Hessian 整流 Newton 步方向余弦 ≥0.99；完整叶求解器的选择分数与对角无差异。

## 7. 优点

- **理论精确性**：梯度、对角及完整 Hessian 全部闭式推导并严格有限差分验证，无近似替代。
- **填补空白**：首次将端到端增长最优目标与 GBDT 结合，不依赖反向传播，使实际量化从业者可同时获得“最佳表格模型”与“精确决策目标”。
- **实验纪律严格**：选择/估计分离、purged walk-forward、embargo、端锚定决策网格、固定留一集成、公开数据与确定种子全可复现，几乎达到“实验室级”金融 ML 规范。
- **透明披露偏差**：主动披露评估段被查看一次并因此加入特征搜索层，不掩盖设计迭代的影响。
- **边界诚实**：不夸大端到端优势，明确展示其失效机制（全 Kelly 集中过度），并通过消融定位到目标与估计误差的交互。
- **工程完备**：提供纯 NumPy 无依赖参考引擎（约 200 行），与 XGBoost 引擎在植入信号问题上一致；完整复现脚本一键运行。
- **附加价值**：CRRA 风险旋钮、置换成本敏感性、移动块 bootstrap 的使用等均体现了严谨的金融度量意识。

## 8. 不足与局限

- **样本量有限**：单宇宙、单评估窗口（13.6 年月度决策），任何方法间的差异均未达到常规统计显著性；bootstrap 区间跨零。
- **评估段泄露（作者主动披露）**：评估段并非严格一次性——手建流程先被评估，表现不佳后添加特征搜索层；虽搜索本身未触碰评估段，但“是否添加搜索”决策受评估结果影响。作者认为该偏差不可能反向解释核心负结果（两阶段胜出），因为两个管线都支持该结论。
- **策略约束**：仅做多、全额投资；杠杆和做空未评估（softmax 的仿射映射是潜在扩展但未验证）。
- **适用规模有限**：成本随 K 线性增长，适用于资产配置（K 较小），不适用于数百资产的选股问题——softmax 单元太小，需扩展分组/稀疏顶层结构。
- **成本模型简化**：主表毛收益，成本敏感性只考虑固定比例单边成本，未包含税收、市场冲击和容量。
- **标签重叠降低有效样本**：清理处理了调参，但日频曲线度量的有效样本仍小于名义长度；bootstrap 块长虽按重叠调整，但信息量仍有限。
- **风险偏好未校准**：全 Kelly 目标本身激进，分数 Kelly 或 CRRA 强度属偏好问题，本文未给出统计选择方法。
