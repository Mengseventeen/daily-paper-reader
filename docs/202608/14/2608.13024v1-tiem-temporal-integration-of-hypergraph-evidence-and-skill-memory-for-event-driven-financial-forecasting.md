## 摘要
事件驱动的催化剂-结果预测越来越多地使用基于检索和记忆增强的大型语言模型代理来进行预测。然而，训练数据污染和时间泄漏可能在报告准确性与真实预测能力之间造成“证据鸿沟”。我们提出了TIEM，一个带有时间戳门控的框架，包含三个协调组件：用于时间戳过滤的多层检索的事件-证据超图（EEH）；用于源标记的时间技能的基于案例的技能记忆（CSM）；以及用于证据-经验融合与预测的异质证据-经验融合推理（HEFR）。我们还引入了FinPURE，一个近期A股保留基准测试，并使用名称-日期探针来评估每个模型的名称-日期敏感性，而不是假设训练截止日期。在五个金融预测基准上的结果表明，TIEM优于当前基线。我们的项目可在 https://github.com/QwenQKing/Fin_TIEM 获取。

## Abstract
Event-driven catalyst-outcome forecasting increasingly uses retrieval- and memory-augmented large language model agents for prediction. However, training-data contamination and temporal leakage can create an Evidence Chasm between reported accuracy and true predictive ability. We propose TIEM, a timestamp-gated framework with three coordinated components: an Event-Evidence Hypergraph (EEH) for timestamp-filtered multi-tier retrieval; a Case-based Skill Memory (CSM) for source-tagged temporal skills; and Heterogeneous Evidence-Experience Fusion Reasoning (HEFR) for evidence-experience fusion and prediction. We also introduce FinPURE, a recent-period A-share holdout benchmark, and use a Name-Date Probe to assess per-model name-date sensitivity rather than assuming training cutoffs. Results on five financial forecasting benchmarks show TIEM outperforms current baselines. Our project is available at https://github.com/QwenQKing/Fin_TIEM.

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：事件驱动（催化剂-结果）型金融预测越来越多地依赖基于检索增强与记忆增强的大语言模型（LLM）智能体。此类方法通常通过检索历史事件证据和调用模型内化经验来完成前瞻性预测。
- **核心问题**：论文指出现有方法存在严重的 **“证据鸿沟”（Evidence Chasm）**——即报告的高准确率与真实预测能力之间的系统性偏差。其根源在于两类数据泄漏：
  - **训练数据污染**：模型预训练阶段可能已见过测试期的事件与结果信息；
  - **时间泄漏**：检索记忆库或模型知识中混入了预测时点之后的信息。
- **整体含义**：在未进行严格时间隔离的情况下，事件驱动预测的评估结果显著虚高，无法反映模型在真实未来事件上的泛化能力。论文旨在同时解决“建模方法”与“可信评估”两个层面的问题。

### 二、方法论：TIEM 框架

TIEM 是一个带**时间戳门控（timestamp-gated）**的三组件协同框架，核心思想是：**在证据检索、技能记忆和推理融合的全链条上强制执行时间隔离**，从而弥合证据鸿沟。

#### 1. 事件-证据超图：EEH（Event-Evidence Hypergraph）

- 构建超图结构，将金融事件（如公司公告、宏观数据发布）与多源证据（新闻、研报、市场数据）连接为高阶关联；
- 采用**时间戳过滤的多层检索**：在每一层检索（如实体关联检索、语义相似检索、超图扩散检索）前，均以预测截止时间为门控条件，剔除未来信息；
- 多层检索确保既覆盖事件间的显式逻辑链，也能捕捉隐含的间接关联，同时不会跨时间域引入污染。

#### 2. 基于案例的技能记忆：CSM（Case-based Skill Memory）

- 将历史案例组织为“技能记忆库”，每个案例附带**来源标签（source tag）**与明确的时间戳；
- 区别于普通向量检索记忆，该模块存储的是“案例→技能”的映射——即从历史事件中抽象出的、可复用的预测模式或决策规则；
- 来源标签和时间戳用于保证技能仅在可合法使用的时间范围内被取出，避免时间泄漏。

#### 3. 异质证据-经验融合推理：HEFR（Heterogeneous Evidence-Experience Fusion Reasoning）

- 将两类异质信息融合：(a) 从 EEH 检索来的多跳事件证据（外部、结构化）；(b) 从 CSM 调用的历史技能经验（内部、模式化）；
- 通过分层注意力或门控机制动态权衡两类信息在不同预测场景下的贡献；
- 在融合表示之上完成最终催化剂-结果的分类预测。

#### 4. 核心机制总结

- **时间戳门控**贯穿整个流水线：所有证据、案例和技能在进入模型前须通过时间戳校验，预测时点之后的任何信息一律过滤；
- 相对于传统 RAG 智能体“先检索、后生成”的范式，TIEM 将时间约束从外部预处理升级为框架内生机制，与检索与记忆模块耦合设计。
