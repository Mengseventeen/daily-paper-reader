## 摘要
大型语言模型越来越多地被用于解读市场、评估风险和配置资本。然而，LLM交易代理的已报告结果可能因前瞻性泄漏、乐观执行以及已描述但未执行的风险授权而虚高。我们提出了OpenPM，一个面向LLM投资组合管理代理的可审计时点评估框架。在OpenPM中，代理使用五分钟间隔的市场数据在标普500指数成分股上管理一个100万美元的多头仓位。代理可见的每一条记录都必须在决策时点可用。自然语言风险授权被转换为类型化约束，并对执行的投资组合强制执行。每次运行都会生成审计产物，包括污染证书、成本敏感性曲线和约束遵守报告。我们还构建了一个名为分层分配器的参考代理，其中类型化分析师对候选资产进行评分，构造器LLM提出权重，确定性评判器保证可行性。我们通过一次捕获分析师证据并在构造器模型之间重放该证据来隔离构造器行为。在我们的短窗口案例研究中，更强的构造器在同一池上相对于等权重显示出适度且依赖于模型的收益，但分析师质量比构造器选择更重要，换手率是主要的成本驱动因素。所有回报都是单一冻结窗口上的上界，不考虑市场影响，而非经过验证的阿尔法。

## Abstract
Large language models are increasingly used to read markets, assess risk, and allocate capital. However, reported results for LLM trading agents can be inflated by look-ahead leakage, optimistic execution, and risk mandates that are described but not enforced. We present OpenPM, an auditable point-in-time evaluation framework for LLM portfolio-management agents. In OpenPM, an agent manages a \$1M long-only book over the S\&P 500 universe using market data at five-minute intervals. Every record visible to the agent must be available at the decision time. Natural-language risk mandates are converted into typed constraints and enforced on the executed portfolio. Each run produces audit artifacts, including a contamination certificate, a cost-sensitivity curve, and a constraint-adherence report. We also build a reference agent named the tiered allocator, where typed analysts score candidates, a constructor LLM proposes weights, and a deterministic critic guarantees feasibility. We isolate constructor behavior by capturing analyst evidence once and replaying it across constructor models. In our short-window case study, stronger constructors show modest and model-dependent gains over equal weighting on the same pool, but analyst quality matters more than constructor choice, and turnover is the main cost driver. All returns are upper bounds on a single frozen window without market impact, not validated alpha.

## 1. 论文的核心问题与整体含义

- **研究动机**：LLM越来越多地被用于金融市场决策（阅读市场、评估风险、配置资本）。然而，现有LLM交易代理的评估结果存在三大系统性缺陷，导致报告业绩虚高、无法在真实部署中复现：
  - **信息泄漏（Information Leakage）**：代理可见的数据中混入了决策时点尚不可知的未来信息（如用未来观测构造的特征、按事件时间而非可用时间打戳的记录）。
  - **乐观执行（Optimistic Execution）**：回报计算未计入买卖价差、滑点和换手成本，得到的是“上界”而非可部署的估计。
  - **未强制执行的风险授权（Unenforced Mandates）**：自然语言风险指令（如“保守”“最多20只股票”）仅用于事后评分，而不会在执行组合上强制执行，模型无视指令也不会被识别。

- **核心问题**：不是“LLM代理在回测中看起来多强”，而是“该结果在真实部署中能否存活”。现有基准缺乏对信息访问、执行成本和约束遵守的严格审计。

- **整体含义**：OpenPM将“可信评估”当作工程制品来构建，提出了一个可审计的**时点（Point-in-Time, PiT）评估框架**。它通过统一可用性门控、类型化约束强制和全套审计产物，让每一个报告的数字都能追溯到产生它的条件，从而防止收益虚报。论文明确声明：所有回报均为无市场影响的单窗口上界，而非已验证的alpha。

## 2. 论文提出的方法论

### 2.1 核心思想
- 以“可用性时间戳门控”为不变量：**任何记录只有在 `ts_available ≤ T` 时才能进入决策状态**，杜绝前瞻性使用信息。
- 将**自然语言风险指令编译为类型化约束**，并由**确定性评判器（critic）在循环内强制执行**，而不是依赖模型自觉或事后检查。
- 每个运行产生**审计工件**（污染证书、成本敏感性曲线、约束遵守报告、偏差检查清单），保证可复现、可追溯。

### 2.2 基准任务设计
- 代理管理一个 **100万美元的多头（long-only）无杠杆账户**，投资于标普500成分股宇宙。
- 每5分钟观察一次市场状态，可按**小时、日、或一次性**节奏再平衡，发出美元计价订单。
- **执行模型**：买入以卖一价（ask）成交，卖出以买一价（bid）成交，即收取“同侧半价差”；交易整股，结构上强制多头和无杠杆（买入不得超过现金，卖出不得超过持仓）。无滑点和市场冲击建模。

### 2.3 点对点数据环境
- 每个记录携带可用性时间戳，进入状态仅当 `ts_available ≤ T`。该门控与事件时间、bar结束时间区分（例如：财报按EDGAR的acceptanceDateTime，宏观序列按FRED/ALFRED的vintage，bar特征在bar收盘后才可用）。
- 代理可见状态包含六类可时点计算的层：
  - **价格/bar**：5分钟收益、波动率、VWAP距离、缺口等（无原始价格水平，用归一化特征，降低价格记忆风险）。
  - **流动性**：价差、报价深度、非流动性标记。
  - **制度（Regime）**：市场/行业相对收益、beta、宽度、曲线斜率、风险偏好。
  - **事件**：盈利时间、EPS惊喜、盈利后漂移。
  - **新闻**：GDELT流量、新近度、标题情绪（发布+30分钟滞后）。
  - **备案（Filings）**：8-K项目代码统计、10-K/10-Q正文段落（通过BM25检索，决策时门控）。

### 2.4 自然语言风险指令编译
- 预设词映射到类型化 `RiskConstraints`：
  - 保守：≤5%单一持仓、≤30只股票、10%现金；
  - 平衡：≤10%单一持仓、≤20只股票；
  - 激进：≤25%单一持仓、≤10只股票。
- 自由文本（如“谨慎的退休者”）通过LLM强制工具调用解析为同一类型化信封，附带置信度；低置信度或矛盾则默认“平衡”。解析发生在配置期，不在泄漏面内。

### 2.5 分层分配器（Tiered Allocator）流程
- 八级流水线，仅分析师和构造器调用LLM，其余阶段确定性：
  1. NL指令 → 类型化约束；
  2. 流动性门控：限制候选池至≤50只可交易名字；
  3. 六名并行分析师（技术、制度、事件、新闻、8-K代码、BM25备案）在点对点数据上打分 `[−1,1]` 并给出置信度；
  4. 确定性流动性分析师给出每名仓位上限；
  5. 置信度加权聚合：`comp(s) = Σ_a w_a c_{a,s} x_{a,s} / Σ_a w_a c_{a,s}`，均匀权重 `w_a=1`；
  6. 更强的构造器LLM通过工具使用提出多头权重（看到分析师矩阵和价差，但看不到原始价格、复合分数或候选顺序；候选已打乱）；
  7. **确定性评判器**将提案投影到可行集（long-only、top-N名数上限、每名和流动性裁剪、现金/总仓/换手缩放）——**可行性由投影保证，而非模型**；
  8. 填充模拟器按报价侧标记执行组合，生成权益曲线和审计日志。

### 2.6 构造器隔离设计
- 先运行分析器层并**冻结输出**为“分析师捕获”（每名分数+置信度），然后在不同构造器间**重放同一捕获**，确保构造器是唯一变量。这是对比公平性的关键。

## 6. 论文的主要结论与发现

1. **LLM构造能力是真实但有条件的**：在强分析师捕获（gpt-5）上，5个构造器中4个能在K=50击败同池等权重（最高+5.3个百分点）；在弱捕获（DeepSeek-V3.2）上，无一击败（最好为−1.0点）。构造器排序稳定：**gpt-5 > Opus-4.7 > DeepSeek-V3.2 > Qwen3-Max > gpt-4o-mini**。
2. **分析师层级是更大的杠杆**：将同一构造器从DeepSeek捕获切换到gpt-5捕获，收益大幅提升；等权重本身变化不大。说明应优先投入分析师计算，再选择最便宜的可用构造器。
3. **确定性评判器必要且有效**：本场景下所有构造器原始提案均满足显式的10%单名上限和20名上限，评判器的主要工作变成了流动性执行（在90个单元中绑定37个，集中于弱构造器）。这说明不能默认模型天然合规，确定性保障层必须在关键路径上。
4. **换手率主导成本，而非价差**：
   - 一次性模式：净利≈毛利（约每交易美元2bp成本）；
   - 每日模式：换手率累计22–44倍，高换手构造器（gpt-4o-mini 41倍、Qwen 44倍）被拖累至低于SPY；低换手率是必要非充分条件（gpt-5换手最低22倍但收益也低），**“选好并少交易”才是胜出模式**。
5. **泄漏审计**：5个构造器的污染证书全部PASS，知识截止均早于2026窗口（最薄Margin为Opus-4.7约2026-01）。
6. **结构性发现而非模型排名**：单名强趋势（如INTC）可驱动构造器间大部分差异；因此强调相对排序与结构结论，而非绝对水平。

## 8. 不足与遗漏

- **评估窗口过短且单一**：仅2026-03-02至2026-05-01共44个交易日，未覆盖跨年度、跨市场制度（牛市/熊市/震荡）、跨资产类别或跨地域；结论外推性存疑。
- **未建模真实执行摩擦**：仅收取同侧半价差，忽略滑点、市场冲击、订单延迟、部分成交、隔夜跳空和融资成本；作者虽声明“上界”，但真实部署的损耗仍可能显著更高。
- **数据源单一性与幸存偏误**：IEX TOPS仅为单场所报价，可能偏离全国最优报价（NBBO）；标普500成分股宇宙本身存在幸存者偏误与大盘股偏向，不适用于小盘或另类资产。
- **新闻与备案信号滞后设置实际效果未充分验证**：GDELT实体解析质量、BM25检索段落与决策的相关性、以及+30分钟滞后是否足以消除新闻相关的前视泄漏，均缺少人工评估或敏感性检验。
- **提示词迭代存在数据窥探风险**：作者承认在重叠数据上反复调整提示词，可能使结果对特定窗口过拟合；论文未提供样本外或滚动前推验证。
- **构造器对比的混杂因素未完全排除**：不同构造器的API版本、随机种子、温度0下的确定性、以及上下文长度截断行为可能存在差异；论文未报告token消耗差异对成本效益的影响。
- **约束投影可能掩盖模型真实违规倾向**：由于评判器强制投影，论文无法直接观测“模型若无约束会如何违反”的分布；合规报告虽区分了授权违例与流动性裁剪，但对前者未做更细粒度定性分析。
- **现金/仓位上限等约束参数由预设词映射而来**：对自由文本指令的LLM解析置信度阈值、默认回退规则等，缺乏消融实验说明其稳定性。
- **计算成本与API资源报告缺失**：未给出每次运行的token数、成本估算、调用失败率、重试策略等，影响经济性评估与复现预算规划。
- **无市场影响的假设过于理想**：100万美元组合在IEX单场所大单执行时实际会影响报价，论文仅声明上界而不做量化估计，可能低估真实交易成本。
- **未与其他非LLM替代方案充分对比**：Baseline仅包括同池等权重、复合排名、随机N和SPY，未包括经典量化方法（如均值方差、风险平价、因子模型、动量策略等），无法判定LLM构造器相对成熟量化方法是否真的具有竞争力。

## 9. 个人思考与启示

- **“可审计性”应成为LLM金融评估的第一公民**：OpenPM的最大贡献并非某个模型或某个收益数字，而是把“数字是否可追溯”这一元标准制度化。任何金融AI论文若不能回答“这个观测在决策时刻是否真的可见”“这个成交价在现实中是否拿得到”，其结论都只能停留在演示层面。
- **强制约束比提示词约束更可靠**：实验表明模型原始提案在显式约束上已基本合规，但在流动性等更细粒度问题上仍会越界。这提示一个通用原则：**凡是能由确定性代码保证的约束，就不要交给模型自觉**；LLM只负责生成意图，合规由代码负责兜底。
- **分析师层与构造器层应分层解耦、分别优化**：该论文的隔离实验证明，分析器质量的边际贡献远大于构造器的选择。这对实践者的直接启示是：先建立高质量、可时点更新的信号捕获层，再在最便宜且能力够用的构造器上做组合构建，而不是一味追求更强LLM。
- **换手率是净收益的第一杀手**：每日模式下高换手构造器即使选择能力再强，也被成本拖垮。这与量化投资中“成本是alpha的天敌”的直觉一致。LLM代理评估必须把换手率和成本敏感性作为核心指标，而不仅是总回报。
- **“上界”思维是负责任的学术表达**：作者反复声明报告的是上界而非可部署收益，这种克制值得借鉴。尤其在金融领域，业绩虚高会直接误导实践者；明确“什么不是结论”与“什么是结论”同样重要。
- **未来方向的可能延伸**：改用NBBO或深度订单簿模拟更真实执行；引入滚动前推（walk-forward）避免数据窥探；扩展到跨市场、跨周期、跨资产类别；将评判器从硬约束投影升级为带惩罚的软约束优化；对自由文本指令解析做概率校准；将token成本纳入构造器排名。
