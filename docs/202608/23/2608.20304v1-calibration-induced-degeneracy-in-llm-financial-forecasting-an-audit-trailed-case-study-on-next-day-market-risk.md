## 摘要
高成本的LLM特征只有在校准允许其影响预测时才有意义。我们在对两只大盘基金的次日风险研究中记录了这种联系的失效。全历史评分先于2022年的校准，而校准随后将所有四个LLM权重设为零，因此后来的856个分数无法影响评估。我们将这种现象称为校准引发的退化。允许带符号的权重重新激活了所有四个映射，但在族系校正后，它们均未改善预测。相比之下，一个近乎零成本的标题计数将SPY的方差预测损失降低了0.001720（95%族系区间：[0.000719, 0.002830]）。因此，这种廉价基线是一个关键的诊断工具。我们提出了一个校准可行性检查点：拟合映射，在预设的校准值上扰动特征，并在获取保留特征之前要求有意义的预测响应。该检查不使用保留结果。在本案例中，它本可以阻止付费的全历史推断阶段。

## Abstract
Costly LLM features matter only if calibration lets them affect the forecast. We document a failure of this link in a next-day risk study of two broad-market funds. Full-history scoring preceded the 2022 calibration. Calibration then set all four LLM weights to zero. The 856 later scores therefore could not affect the evaluation. We call this calibration-induced degeneracy. Allowing signed weights reactivated all four mappings. None improved forecasts after familywise correction. By contrast, a near-zero-cost headline count reduced SPY variance-forecast loss by 0.001720 (95 percent familywise interval: [0.000719, 0.002830]). The cheap baseline is therefore a critical diagnostic. We propose a calibration-viability checkpoint. Fit the mapping, perturb the feature over prespecified calibration values, and require a meaningful forecast response before acquiring holdout features. The check uses no holdout outcomes. Here, it would have stopped the paid full-history inference phase.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：昂贵的LLM生成特征在金融预测中是否有价值，取决于校准（calibration）是否为该特征保留了一条通往预测结果的路径。若校准将特征权重压缩为零，则该特征是数学上无关的，无论后续获取多少分数都无法影响预测。
- **具体失败案例**：研究者在一次次日风险实验中，先获取了856个后续日期的LLM评分，随后才执行2022年校准；结果校准将全部四个LLM重要性权重设定为0，导致所有后期采集的数据在评估中**完全失效**。论文将这种因时序安排不当导致的失效称为**"校准引发的退化"（calibration-induced degeneracy）**。
- **整体含义**：
  - 该论文揭示了标准LLM特征采集流程中的一个隐蔽漏洞：即便遵守了防前瞻（no look-ahead）和防过拟合规则，"权重为0"也是一种合法的嵌套模型选择，但这些安全措施并不保证特征能真正参与预测。
  - 论文给出了一种廉价的治理工具：**校准可行性检查点**，用于在付费获取大规模特征之前判断该特征对预测有没有机械的、有意义的响应。
  - 论文强调了**廉价基线（如标题计数）作为关键诊断对照**的重要性——让昂贵的语义特征必须战胜一个"几乎免费的统计量"，否则不值得使用。

## 2. 方法论：核心思想、关键技术细节与流程

论文的核心方法论贡献是提出的**校准可行性检查点（Calibration-Viability Checkpoint）**，其操作规则为：**先拟合（fit），再扰动（perturb），满足阈值后才获取（acquire）**。

- **核心思想**：在校准阶段就检查特征是否在机械上具有激活能力。如果一个特征在校准拟合后改变其对预测结果的输入值时，预测输出几乎不变，那么该特征的后续采集是没有意义的。
- **关键公式**：
  - 令 \( \hat{f}_A(x, s) \) 为包含候选特征 \( s \) 的校准后增强预测，\( \hat{f}_B(x) \) 为基线预测。
  - 当 \( \hat{f}_A(x, s) = \hat{f}_B(x) \) 对所有合理 \( s \) 成立时，该模型称为退化的（degenerate）。
  - 可行性的量化定义（最大预测差异）：
\[
D = \max_{x \in X} \max_{s,s' \in S} \left| \hat{f}_A(x, s) - \hat{f}_A(x, s') \right|
\]
其中：
  - \( S \) 是特征支持网格（实际建议为校准样本中的第10、50、90百分位数，外加最小和最大值）；
  - \( X \) 是锚定输入（从低、中、高基线风险预测行中选取）；
  - \( \delta \) 是预先设定的有意义变化阈值。
- **决策规则**：
  - \( D = 0 \)：机械不可行（calibration_nonviable）；
  - \( 0 < D < \delta \)：操作性过弱（calibration_too_weak）；
  - \( D \ge \delta \)：可继续获取并评估。
- **五步流程**：
  1. **冻结门控**（指定基线/增强模型、昂贵特征与廉价对照、校准行、支持网格、阈值δ、备用方案）；
  2. **先拟合后获取**（只允许使用校准数据，不购买、不暴露保留特征）；
  3. **扰动特征**（固定其他输入，在冻结支持网格上扫掠，计算D）；
  4. **分类可行性**（停止或执行冻结的备用方案）；
  5. **通过后才获取**（生成保留特征，锁定映射，与强基线和廉价对照同时评估）。
- **统计框架**：
  - 二元端点用对数损失（log loss），连续方差端点用高斯拟似然损失（QLIKE，对噪声方差代理稳健）；
  - 采用20天移动块自助法（moving-block bootstrap），20,000次抽样，区间覆盖有普通95%和Bonferroni族系校正两种；
  - 嵌套模型评估注意点：后验块区间仅以固定2022映射为条件，不是Clark-West或Clark-McCracken检验。

## 6. 主要结论与发现

1. **校准引发退化**：预设的非负权重约束[0,5]使得全部四个LLM重要性系数在大约2022年校准中收敛到0。由于边界解对应零权重，新闻模型与VIX/VXN基线预测完全相同，856个后续评分在代数上不可能影响评价。
2. **有符号修复未改善预测**：将约束放宽为[-5,5]后，所有四个映射的最优点移到负内部值（负斜率是"条件调整"而不是"重要新闻本身降低风险"的因果证据），但所有端点改进均为非正；四个端点的族系校正区间均含0或无净正增益。
3. **廉价标题计数有效**：标准化对数标题计数在**SPY连续方差端点**上改进显著：改进量为0.001720，95%族系校正区间为[0.000719, 0.002830]，排除零。但它同时对SPY二元和QQQ方差有害、QQQ二元增益在族系校正后不能分辨，并非普遍优越。
4. **层级诊断的启示**：LLM评分的原始秩相关（SPY 0.1413，QQQ 0.1284）在条件化VIX/VXN后降至约0.05，表明该分数对期权价格没有增量预测价值。诊断的关键是对比"廉价特征是否胜过昂贵特征"，而不是未校正的相关性。
5. **方法论处方**：任何LLM金融特征实验都应先拟合、后扰动、仅当D ≥ δ时才获取保留历史。此检查不使用保留结果，完全在校准数据上运行。

## 7. 优点

- **审计追踪堪称典范**：
  - 每个阶段保存了SHA-256指纹、原始API响应、下载地址、清理文件、精确成本、验证脚本和运行日志；

- **廉价基线诊断的引入**：用标题计数这一近乎零成本的统计特征作为"语义特征有用性"的自然底线，逻辑非常清晰：昂贵语义特征必须证明自己比廉价的体积统计更值得。

- **正面给出可操作的停机规则**：将统计上的"徒劳监测"概念转化为适用于低成本特征获取的设计要求。

## 8. 不足与局限

- **最大的时间威胁**：
  - 提示词问的是"未来1–5个交易日的重要性"，而目标测量的是"收盘后到次日收盘的下一天风险"；信息可能在收盘前已部分反映在价格中（时序错配）；
  - LLM看到确切的过去日期，可能记忆了著名事件——"不要使用事后名气"的指令无法消除预训练记忆。无日期遮蔽的再评分实验（date-masked rescoring）未执行。
- **实验者预期风险**：作者在另一项目（Hybrid v1.10）中已接触过同一SPY日历期的实际结果，可能影响提示词选择和推进决策（尽管无法机械地进入冻结的系数拟合）；QQQ/VXN未受此污染但非独立复制。
- **外部效度有限**：
  - 仅覆盖一种LLM族、一个线性映射、两种大盘ETF（SPY/QQQ），不涵盖个股、独立复制或跨机构设置；
  - 新闻数据构造依赖固定的词语查询、白名单域名、爬取时间戳、模糊去重和顶部25条上限，不同的构造可能改变结果；
  - 校准仅使用2022年数据（无同等的更早v4年份），新预测窗口未必复现边界解；
  - 大幅波动事件稀少（40/46个），无预先功效分析，预设比较在零斜率时检验力为零。
- **统计充分性有限**：
  - 每主样本日期仅一次随机生成；无重复运行可靠性、无金融专家一致性检验、无显式测量误差模型；
