## 摘要
量子自然语言处理（QNLP）为文本建模提供了语法感知框架，而分布合成范畴（DisCoCat）是其具有理论基础的表述之一。先前关于金融情感分析的研究已识别出DisCoCat的实际局限性，包括解析器敏感性、高模拟成本以及难以处理较长句子。我们研究了一种LLM辅助的预处理工作流，通过受控改写来压缩、简化或分解中等复杂度的金融情感句子，使其成为解析器兼容、电路高效的形式，同时保留承载情感的意义。我们将提示策略、语言模型和过滤配置与Stein等人的仅低复杂度DisCoCat基线进行比较。在电路层面，最强的压缩变体相对于原始中等复杂度子集，平均量子比特数和门数减少了70%以上。在重复训练运行中，使用Prompt B的GPT-4.1-mini达到了观测到的最高平均准确率，$0.550 \pm 0.035$，而基线为$0.521 \pm 0.050$。更大的训练分割并不必然提高下游性能；在评估的配置中，训练分割大小与准确率呈中等负相关（Pearson $r=-0.446$）。这些结果提供了探索性证据，表明LLM辅助改写可以使某些中等复杂度输入在所评估的DisCoCat配置中可用，同时突显了提示设计、过滤和电路感知预处理对于更可扩展的基于QNLP的金融情感分析的重要性。

## Abstract
Quantum natural language processing (QNLP) provides a grammar-aware framework for text modeling, and Distributional Compositional Categorical (DisCoCat) is one of its theoretically grounded formulations. Prior work on financial sentiment analysis has identified practical limitations of DisCoCat, including parser sensitivity, high simulation cost, and difficulty handling longer sentences. We study an LLM-assisted preprocessing workflow that uses controlled rewriting to compress, simplify, or decompose moderate-complexity financial sentiment sentences into parser-compatible, circuit-efficient variants while preserving sentiment-bearing meaning. We compare prompting strategies, language models, and filtering configurations with the low-complexity-only DisCoCat baseline of Stein et al. At the circuit level, the strongest compression variants reduce average qubit and gate counts by more than 70 percent relative to the raw moderate-complexity subset. Across repeated training runs, GPT-4.1-mini with Prompt B achieves the highest observed mean accuracy, $0.550 \pm 0.035$, compared with $0.521 \pm 0.050$ for the baseline. Larger training splits do not necessarily improve downstream performance; across evaluated configurations, training-split size has a moderately negative association with accuracy (Pearson $r=-0.446$). These results provide exploratory evidence that LLM-assisted rewriting can make some moderate-complexity inputs usable within the evaluated DisCoCat configuration, while highlighting prompt design, filtering, and circuit-aware preprocessing as considerations for more scalable QNLP-based financial sentiment analysis.

## 1. 论文的核心问题与整体含义

- **研究动机**：量子自然语言处理（QNLP）中的 DisCoCat 框架虽然具备语法感知的文本建模能力，但在金融情感分析应用中面临三大实际限制：解析器敏感、模拟成本高、难以处理较长或更复杂的句子。已有工作（Stein et al. 2023）在低复杂度句子上表现尚可，但一旦遇到平均约 18 个词的中等复杂度金融句子，DisCoCat 的实用性和可扩展性明显下降。
- **核心问题**：能否通过 LLM 辅助的受控改写（rewriting），将中等复杂度的金融情感句子压缩、简化或分解成更易解析、电路更高效、且保留情感含义的形式，从而使这些句子在现有 DisCoCat 配置下可用于端到端训练？
- **整体含义**：这项研究并非主张 QNLP 替代 Transformer 方法，而是探索一种“预处理层”思路：把 LLM 视为改写工具而非最终分类器，通过提示词控制改写结果，为后续量子 NLP 管线提供更友好的输入。论文整体定位为“探索性概念验证”，目标是向更可扩展、更具实用性的 QNLP 金融情感分析迈出一步，而非宣称通用精度提升或达到可部署水平。

## 2. 论文提出的方法论

- **核心思想**：利用 LLM 对原始中等复杂度金融句子进行受控改写，将改写产物经过语义、情感、解析有效性三重筛选后，与低复杂度基线数据合并，再送入基于 lambeq 的 DisCoCat 管线训练情感二分类模型。
- **关键技术细节**：
  - **三种提示改写策略**：
    - Prompt A：语义压缩（1-to-1），将原句缩短为更短的单句，同时保留主要金融含义和情感极性。
    - Prompt B：解析器友好改写（1-to-1），在压缩基础上增加结构约束，使输出更容易被 BobcatParser 解析。
    - Prompt C：分解策略（1-to-many），把一个原句拆成多个较短的独立句子，适用于包含多个可分离语义单元的情况。
  - **数据集构造公式**：对每个变体 $v$，最终数据集定义为 $D(v) = D_L \cup A(v)$，其中 $D_L$ 为低复杂度基线，$A(v)$ 为该变体的可接受改写输出。
  - **筛选与过滤**：
    - 语义保持：用 MeaningBERT 计算改写句与原始句的相似度得分 $s_i$；
    - 情感一致性：用 FinBERT 对改写句预测情感并与原始标签比对，对 Prompt C 的输出按多数投票聚合为原句标签；
    - 解析有效性：用 BobcatParser 检查改写句能否成功生成语法图。
  - **两种数据集构建策略**：
    - Strategy A：只保留解析有效的输出，不做额外过滤；
    - Strategy B：在解析有效基础上，要求情感一致且 MeaningBERT 相似度 $s_i \ge t$（$t \in \{40,50,60,70,80\}$）。最终实验采用 $t \ge 60$ 作为探索性工作点，未在留出数据上优化。
  - **下游 DisCoCat 训练流程**：句子经 BobcatParser 解析为语法图，再转为 DisCoCat 图，最后映射为量子电路；使用 IQPAnsatz、TketModel、AerBackend（statevector 模拟），训练 100 epochs，batch size 32，优化器为 SPSAOptimizer，训练/验证/测试比例为 80%/10%/10%。
  - **数据泄漏控制**：对 Prompt C 产生的同一原句的多个分解句，分配组标识，按组切分数据，避免训练/验证/测试集之间信息泄漏。

## 6. 论文的主要结论与发现

- **改写能显著降低电路复杂度**：相对于原始中等复杂度子集，最强的 GPT-4.1-mini + Prompt A 组合将平均量子比特数从 23.16 降到 5.60（减少 75.81%），门数从 118.07 降到 27.29（减少 76.88%）；Prompt B 也有约 70% 左右的量子比特数和门数降幅。深度减少较小（约 30%），说明深度受语法结构影响更大。
- **不同 Prompt 起不同作用**：
  - Prompt A 和 B 通过直接压缩句子长度降低电路复杂度；
  - Prompt C 通过分解降低单句电路复杂度，但保留更多输出、总计算成本更高。
- **无单一策略在各方面都最优**：
  - Prompt C 的 MeaningBERT 相似度和 FinBERT 情感一致性最高；
  - Prompt B 的 Bobcat 解析成功率最高；
  - Prompt A 的电路压缩最激进。
- **分类性能**：
  - GPT-4.1-mini + Prompt B 取得最高平均测试准确率：$0.550 \pm 0.035$，高于基线 $0.521 \pm 0.050$；
  - GPT-4.1-mini + Prompt A（过滤）准确率接近（$0.549 \pm 0.026$），运行时间更低；
  - Prompt C 虽然保留训练数据最多（扩展比达 3.18× 和 3.65×），但准确率反而更低（约 0.465–0.493），运行时间却大幅上升。
- **训练数据量不是越多越好**：在 53 次运行中，训练分割大小与准确率呈中等负相关（Pearson $r=-0.446$，Spearman $\rho=-0.342$），说明改写后的数据质量和组成比单纯增加数量更重要。
- **总体定位**：结果为“LLM 辅助改写可使部分中等复杂度合成金融句子通过当前 DisCoCat 配置进行训练”提供了探索性证据，但不代表通用精度优势或最优预处理方案。

## 7. 优点

- **问题选择有实际意义**：精准命中 DisCoCat 在金融场景下的真实瓶颈，即长句、复杂句导致的解析失败和电路膨胀。
- **思路新颖**：把 LLM 从“最终预测器”转为“前置改写器”，避开了 LLM 直接做分类的路径，强调与语法约束管道结合。
- **多层次评估框架**：同时评测文本长度、量子比特数、电路深度、门数、语义相似度、情感一致性、解析成功率、数据扩展比、准确率和运行时间，而不是只看最终精度。
- **对 Prompt C 的数据泄漏处理**：对分解输出按原句分组切分数据，避免组内信息泄漏，设计细致。
- **诚实的边界声明**：论文反复强调结果是探索性的、非因果、非最优，没有夸大结论；对失败的 Qwen Prompt A/C 运行也有明确报告。
- **可复现性意识**：提供代码仓库，记录了模型版本、软件栈、硬件环境等细节。

## 8. 不足与局限

- **实验对照不足**：缺少经典 NLP 基线、非 LLM 改写基线、规则简化基线；没有把“改写”和“过滤/解析选择”的效果完全剥离。
- **统计严谨性有限**：只有 5–6 次重复，未做显著性检验、置信区间或效应量估计，最高精度与基线的差异只能描述性解读。
- **合成数据局限性**：数据由 ChatGPT 生成，不能代表真实金融新闻、社交媒体或公司披露的多样性、噪声和语境结构。
- **过滤方法为代理指标**：MeaningBERT 和 FinBERT 只是语义与情感估计，无法完整捕捉命题保留、否定、实体、金融事件等细粒度信息；没有人工评价。
- **阈值选择有偏差风险**：$t \ge 60$ 未在留出数据上优化，可能对结果造成乐观或选择偏差。
- **模型对比不完整**：Qwen2.5:7B 的 Prompt A 和 C 因训练时维度错误失败，导致跨模型结论仅限 Prompt B，实验覆盖度不足。
- **成本评估不完整**：运行时间只有整体统计，没有按 LLM 改写、筛选、解析、电路构造、训练的分阶段拆解；分解策略可能“单电路变小但总工作量增加”。
- **技术栈依赖性强**：结论绑定当前 Bobcat 解析器、lambeq、AerBackend 模拟器、模型版本和解码设置，改用其他量子后端或解析器可能得到不同结果。
- **扩展性未验证**：没有在硬件量子设备上运行，没有评估电路编织等分布式量子计算近似方案的有效性。
