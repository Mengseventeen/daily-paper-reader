## 摘要
我们提出了一种无套利感知的潜在流匹配框架，用于无条件隐含波动率曲面的生成。该方法首先使用变分自编码器将高维曲面压缩到低维潜在空间，并通过可微分的日历价差、看涨价差和蝶式套利罚项进行正则化。随后，流匹配模型学习将高斯先验分布传输到经验潜在分布，并将生成的潜在样本解码回波动率曲面。我们使用边际和曲面级别的Wasserstein距离、微笑和偏斜诊断、逐点分位数曲面、金融可解释的形状指标以及静态无套利测试来评估该方法。所提出的模型能够紧密复现经验分布和主要期限-货币性结构，在极端Q99区间内取得最佳性能，并生成90.8%的满足所有测试的静态无套利条件的曲面。总体而言，结果表明，潜在流匹配在无需后采样重新加权的情况下，能够在分布相似性、尾部保持和金融一致性之间提供良好的平衡。

## Abstract
We propose an arbitrage-aware latent flow-matching framework for unconditional implied volatility surface generation. The method first compresses high-dimensional surfaces into a low-dimensional latent space using a variational autoencoder regularized by differentiable calendar-spread, call-spread and butterfly-arbitrage penalties. A flow-matching model then learns to transport a Gaussian prior toward the empirical latent distribution, and generated latent samples are decoded back into volatility surfaces. We evaluate the approach using marginal and surface-level Wasserstein distances, smile and skew diagnostics, pointwise quantile surfaces, financially interpretable shape metrics, and static no-arbitrage tests. The proposed model closely reproduces the empirical distribution and the main maturity-moneyness structures, achieves the best performance in the extreme Q99 regime, and generates 90.8% of surfaces satisfying all tested static no-arbitrage conditions. Overall, the results show that latent flow matching provides a favorable balance between distributional similarity, tail preservation, and financial consistency without requiring post-sampling reweighting.

- **研究动机**：隐含波动率曲面（IVS）是期权市场信息的核心载体，准确建模对衍生品定价、对冲、风险管理和压力测试具有重要意义。然而，传统参数化模型（如 SVI、随机/局部波动率模型）虽然可解释且容易加入金融约束，但难以完整复现市场曲面的经验分布；而深层生成模型（GAN、VAE、扩散模型）虽然能学习数据分布，却常常生成“视觉上合理但金融上无效”的曲面——即违反静态无套利条件。
- **核心问题**：如何在生成隐含波动率曲面时，同时满足两项目标：
  1. 统计真实性：尽量贴近经验边际分布、微笑/偏斜结构以及尾部行为；
  2. 金融一致性：控制或减少日历价差、看涨价差和蝶式套利的静态无套利违规。
- **整体含义**：论文提出一种“无套利感知的潜在流匹配”（Latent Flow Matching, L-FM）框架，试图在不依赖采样后重加权的情况下，在分布保真度与金融有效性之间取得平衡。该框架可为合成情景生成、压力测试、风险分析和数据增强提供基础。

## 2. 论文提出的方法论

- **总体框架（两阶段）**：
  1. 第一阶段：训练一个**带无套利正则的变分自编码器（Arbitrage-Regularized VAE）**，将高维 IVS（512 维）压缩至低维潜在空间（默认 6 维）；
  2. 第二阶段：在潜在空间中训练**流匹配模型**，学习将高斯先验分布传输到经验潜在分布的时间相关向量场；
  3. 采样时，从高斯先验采样潜在码，通过求解学到的 ODE 得到终态潜在变量，再经解码器映射为生成曲面。

- **关键技术细节**：
  - **VAE 编码器**：输出对角高斯后验参数，使用重参数化技巧采样潜在变量；
  - **解码器正则化**：在标准重建损失 + KL 正则基础上，增加三类无套利罚项：
    - `L_cal`：日历价差罚项，惩罚相邻到期日隐含波动率下降；
    - `L_but`：蝶式套利罚项，基于 Gatheral–Jacquier 判据（g(τ, k) ≥ 0），用中心差分近似总隐含方差对 log-moneyness 的一阶、二阶导数；
    - `L_call`：看涨价差罚项，惩罚同一期限下隐含波动率随 moneyness 上升；
  - **完整 VAE 损失**：`L_VAE = L_rec + β L_KL + λ_cal L_cal + λ_but L_but + λ_call L_call`；
  - **流匹配模型**：学习向量场 `v_ψ(t, z_t)`，采用**三角函数路径**（trigonometric interpolation）：
    - `I_t(z0, z1) = cos(πt/2) z0 + sin(πt/2) z1`
    - 目标速度为 `u_t = -(π/2) sin(πt/2) z0 + (π/2) cos(πt/2) z1`
  - 训练损失为流匹配损失 `L_FM = E[||v_ψ(t, z_t) − u_t(z0, z1)||²]`；
  - 采样时使用 100 步 Euler 积分求解 ODE。

- **设计优势**：潜在空间建模降低生成任务维度；解码器作为潜在变量到曲面的结构映射，使流模型可专注于学习市场相关潜在因子的分布。
