## 摘要
反事实分析旨在预测假设情景下的潜在结果，为决策提供有价值的见解。本文研究了大型语言模型（LLMs），特别是GPT-3.5模型，在反事实分析中的应用。我们聚焦于在线借贷场景，其中反事实的投资回报率（ROI）对于评估不同利率方案至关重要。我们首先评估GPT的预测性能，并将其与先进的机器学习算法进行比较。结果表明，提示工程可以显著提升GPT的预测能力，R平方从1.97%增至2.84%，接近梯度提升回归所达到的3.48%。随后，我们利用GPT在一组替代利率下生成反事实ROI。GPT在回答中展现出逻辑一致性和因果推理能力。研究结果突显了LLMs作为在线借贷中反事实分析有效工具的潜力，并暗示LLMs在各类预测和决策情境中的更广泛应用。

## Abstract
Counterfactual analysis aims to predict potential outcomes under hypothetical scenarios, offering valuable insights for decision-making. This paper investigates the application of large language models (LLMs), specifically the GPT-3.5 model, for counterfactual analysis. We focus on the online lending context, where the counterfactual return on investment (ROI) is crucial for evaluating different interest rate schemes. We begin by assessing the predictive performance of GPT and comparing it with advanced machine learning algorithms. The results show that prompt engineering can significantly enhance GPT's predictions, with the R-squared increasing from 1.97% to 2.84%, closely approaching the 3.48% achieved by gradient-boosted regression. Subsequently, we utilize GPT to generate counterfactual ROIs under a set of alternative interest rates. GPT exhibits logical coherence and causal reasoning in its responses. The findings underscore the potential of LLMs as effective tools for counterfactual analysis in online lending, suggesting broader applications for LLMs in various predictive and decision-making contexts.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：如何利用大型语言模型（LLM）进行反事实分析。反事实分析旨在回答“如果……会怎样”的问题，例如利率改变后贷款的投资回报率（ROI）会如何变化。传统方法依赖匹配、随机对照试验、生存分析等，但存在数据需求高、模型灵活性有限等问题。
- **研究动机**：LLM 在大规模文本数据上预训练，具备丰富的世界知识和因果推理潜力，可能比传统预测模型更接近真实世界复杂性。本文希望验证 LLM 能否作为反事实分析的有效工具，尤其是在在线借贷这一信息丰富、决策关键的场景中。
- **整体含义**：如果 LLM 能生成逻辑一致且合理的反事实结果，将极大拓展其在金融、政策评估、个性化决策等领域的应用空间，并为“人机协作”提供新思路。

### 2. 提出的方法论：核心思想与技术细节

- **核心思想**：将贷款与借款人的结构化信息转化为文本提示，利用 GPT-3.5 预测贷款结果（是否付清或违约，以及持续时间），进而计算 ROI；在此基础上，给定替代利率，让模型生成反事实的贷款结果。
- **关键技术细节**：
  - **ROI 分解**：直接预测 ROI 很困难，故分解为两个子任务：预测贷款状态（fully paid / charged off）和预测持续月数，再据此重建现金流并计算 ROI。
  - **提示工程（Prompt Engineering）**：
    - **角色扮演**：让 GPT 扮演“借款人”或“信用风险评估专家”。结果发现扮演借款人会出现“社会期望偏差”（预测违约率远低于实际），而扮演专家则显著提升预测。
    - **信息集扩展**：逐步加入平台级统计信息、机器学习预测结果等。
    - **链式思考（Chain-of-Thought）**：要求模型展示思考过程，逐步推理。
    - **树状思考（Tree-of-Thought）**：模拟多位专家协作讨论、相互修正，最终达成共识（文中采用 3 或 4 位专家）。
  - **人机协作**：将机器学习（ML）预测作为提示的一部分，让 LLM 批判性地参考 ML 结果，而不是简单重复。
  - **偏差校正**：由于 LLM 预测可能存在嵌入偏差，作者将实际 ROI 对预测 ROI 做线性回归，用校准后的预测计算 R²，确保与 ML 比较的公平性。
  - **预测包含检验（Encompassing Test）**：使用回归 `ROI = c + φ·ROI_LLM + (1−φ)·ROI_ML + ε` 检验 LLM 预测是否包含 ML 未提供的信息。φ 显著为正说明 LLM 有增量预测能力。
  - **反事实提示设计**：向 LLM 提供贷款信息、借款人信用档案、平台统计、实际结果（原始利率下），以及 ML 给出的反事实预测（基于混合治愈模型），要求四位专家讨论形成共识，以 JSON 格式输出状态和时长。

### 6. 主要结论与发现

- **提示工程显著提升 LLM 预测能力**：R² 从基础提示的 1.97% 提升至树状思考（4专家）的 2.84%，接近梯度提升回归的 3.48%。
- **LLM 具有增量预测信息**：预测包含检验中 LLM 系数在加入 ML 提示后变得显著为正（如列 7 系数 5.19%，1% 显著性），表明 LLM 不重复 ML，而是补充额外信息。
- **角色扮演影响极大**：让模型扮演借款人时预测严重低估违约率（1.7% vs 实际 12.3%），扮演专家则大幅改善，说明角色设定直接影响模型输出质量。
- **LLM 反事实结果逻辑连贯**：85.3% 的结果符合“利率提高后违约仍违约”规则，99.6% 符合“利率降低后付清仍付清”规则；GPT-4o 能达到 100%。
- **LLM 可修正 ML 错误**：例如混合治愈模型预测替代利率下违约率仅 6.22%，而 LLM 预测为 9.65%，更接近原始违约率 12.34%，被认为更合理。
- **整体结论**：LLM 是反事实分析的可行、有效工具，尤其在在线借贷场景中能结合因果推理与丰富知识，生成可用的反事实 ROI。
