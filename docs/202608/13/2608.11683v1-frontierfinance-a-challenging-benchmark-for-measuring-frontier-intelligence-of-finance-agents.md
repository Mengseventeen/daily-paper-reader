## 摘要
人工智能智能体正越来越多地被部署用于专业投资研究，然而尚无基准能够捕捉完整投资者工作流程的复杂性。现有基准主要针对金融数据提取，这是当前模型已基本饱和的一个狭窄领域，而基于参考的指标和通用的LLM作为评判者的评分在真实分析师查询所需的开放式、长形式答案上表现不足。我们推出了前沿金融（FrontierFinance），一个完全开放的基准，包含220个专家精心设计的查询和11,543个来源归属的评分细则，覆盖完整投资者工作流程中的六个关键用例。前沿金融比现有的公共金融基准更广泛且更具挑战性。在仅限于公开数据集的统一测试环境下评估前沿模型和智能体系统，我们发现工具环境（而非单独的模型）对质量和效率有重大影响；Samaya的内部系统以56.0%的成绩领先，比最强前沿模型（Claude Fable 5，49.2%）高出约2.2倍的成本效益；最佳开源权重模型（Kimi K3，46.4%）以4.5倍的成本优势几乎媲美最佳专有模型。筛选与发现以及行业、产业与宏观仍然是所有系统中最难的用例，即使最佳系统也只达到33%和39%。我们公开了数据集和评分代码。

## Abstract
AI agents are increasingly deployed for professional investment research, yet no benchmark captures the complexity of the full investor workflow. Existing benchmarks mainly target financial data extraction, a narrow slice that current models have largely saturated, while reference-based metrics and generic LLM-as-a-judge scoring fall short on the open-ended, long-form answers that real analyst queries demand. We introduce FrontierFinance, a fully open benchmark of 220 expert-crafted queries and 11,543 source-attributed rubrics spanning six crucial use cases across the full investor workflow. FrontierFinance is both broader and harder than existing public finance benchmarks. Evaluating frontier models and agent systems under a common harness restricted to publicly available data, we find that the tool harness, not the model alone, strongly shapes quality and efficiency; that Samaya's in-house system leads at 56.0%, ahead of the strongest frontier model (Claude Fable 5, 49.2%) at roughly 2.2x lower cost; and that the best open-weight model (Kimi K3, 46.4%) nearly matches the best proprietary model at 4.5x lower cost. Screening & Discovery and Sector, Industry & Macro remain the hardest use cases across all systems, where even the best systems reach only 33% and 39%. We make the dataset and grading code publicly available.

## 1. 核心问题与整体含义

- **研究动机**：AI Agent 正越来越多地应用于专业投资研究，但现有金融评测基准存在三方面不足：
  1. 主要聚焦于**金融数据抽取**（如从财报中提取数字），这类任务已被当前模型基本“饱和”；
  2. 数据记忆（memorization）会污染静态基准的性能评估，模型可能靠训练数据记忆而非真实推理作答；
  3. 真实分析师需要开放式、长表格/长文本研究报告，而现有基于参考文本的指标和泛化 LLM-as-a-judge 打分难以评估这类答案。
- **核心问题**：是否能够构建一个覆盖**完整投资者工作流**、足够难、且可客观复现的金融 Agent 评测基准？
- **整体含义**：论文提出了一个开放基准 **FrontierFinance**，它不只测试“找数值”，而是测试 Agent 在真实投资研究中的开放性发现、多源检索、综合分析、长文报告生成等能力，填补了现有基准的空白。

## 2. 方法论

- **核心思想**：用“专家撰写查询 + 细粒度二元评分细则（rubric）+ 来源归属”来把开放式长回答拆解为可独立验证的二元标准，然后以“rubric 达标率”作为总评分，避免整体打分的主观性和不可解释性。
- **数据收集流程（四阶段）**：
  1. **查询起草**：由前买方分析师、卖方研究助理、投行专家等映射完整投资工作流，写出反映真实任务的开放式查询；刻意保留现实中的模糊性（如公司名与代码混用、多季度动态时间范围、不限定检索范围）。
  2. **专家 rubric 标注**：为每条查询编写二元评价细则，并标注与之对应的**一级公共数据源类别**（如 SEC 文件、电话会纪要、市场数据等）。
  3. **专家审查与 AI 辅助清理**：第一组专家消除主观措辞、重复信息；第二组专家确认每个细则可依据公开证据客观判是否满足，合并冗余细则，并给每个细则打上“必备（must-have）/补充（supplementary）”标签及内容类别。
  4. **再平衡与分层**：从内部 4500+ 条完整标注查询中，按用例、能力、难度三个维度分层抽样，公开 220 条查询（共 11,543 条 rubrics）。
- **时间戳标注**：每条查询携带一个查询日期，rubric 反映截至该日期的世界状态，排除预测性问题，从而避免评测受数据快照影响。
- **难度建模**：用 **Bradley–Terry (BT) 模型**在内部 4212 条查询上拟合潜在难度分数。三位 LLM 裁判对成对查询进行“哪个更难”的判断，依据五个维度（检索广度、推理深度、实体范围、时间范围、定性模糊度），并使用置信度加权负对数似然进行估计：
  \[
  \hat{\theta} = \arg\min_\theta \; -\sum_k c(m_k)\log\sigma(\theta_{w_k}-\theta_{\ell_k}) + \lambda\|\theta\|_2^2
  \]
  其中 \(c(m)\) 为置信度权重，\(\sigma\) 为逻辑函数，\(\lambda=10^{-3}\)。
- **评测指标**：每条查询的 rubric 达标率 \(Q_i = \frac{1}{M_i}\sum_{j=1}^{M_i} s(r_{i,j}, a_i)\)；数据集级采用**宏平均**：
  \[
  R = \frac{1}{N}\sum_{i=1}^N Q_i
  \]
  每个 rubric 由三个 LLM 裁判（GPT 5.4、Gemini 3.1 Pro、Claude Sonnet 4.6）独立判断，取多数票确定是否达标。

## 3. 实验设计

- **基准数据集**：FrontierFinance 本身（220 queries、11,543 rubrics，覆盖六个用例：金融数据抽取、行业/产业/宏观、盈利与事件、公司研究、覆盖与催化剂监控、筛选与发现）。此外还对比了三个公开基准：FinanceBench（150 例）、BigFinanceBench（50 例）、Finance Agent Benchmark v2（27 例），用共同 BT 尺度比较难度。
- **对比系统**：在三种 harness 下评测：
  1. **Web Search Harness**：最小化 harness，模型自带网页搜索工具，作为基线。
  2. **Finance Agent v2 Harness**：开源 harness，聚合六个工具（SEC EDGAR API、市场价格 API、网页搜索、HTML 解析、长 HTML 检索、计算器），限制 200 次工具调用和 300 秒。
  3. **Samaya In-house Harness**：生产级 harness，含自定义模型、工具、数据索引和检索引擎，并额外设置检索截止日期。
- **评测模型**：包括 Claude Opus 4.8、GPT 5.5、Gemini 3.1 Pro、Claude Fable 5、GPT 5.6 Sol、Kimi K3、Gemini 3.6 Flash、GLM 5.2、DeepSeek V4 Pro 以及 Samaya 内部系统两个配置，共十余个系统条目。
- **评测维度**：答案质量（rubric 达标率）、平均延迟（秒）、平均成本（美元，仅计 agentic LLM 的 API 费用）。
- **附加分析**：对 FA-v2 harness 下的模型进行了推理努力（reasoning effort）的消融实验（如 low/medium/high/max）；对四个高表现模型进行轨迹分析，统计工具调用类型、并行度、URL 来源（参数知识 vs 搜索历史）等。

## 6. 主要结论与发现

- **工具 harness 比模型本身更重要**：Samaya 内部 harness 表现最好（56.0%），远超 Web Search harness（最好仅 33.0%）；在 FA-v2 harness 下最好模型为 Claude Fable 5（49.2%）。Harness 显著影响质量与效率。
- **开源权重模型性价比突出**：最好的开源模型 Kimi K3 达 46.4%，几乎追平 GPT 5.6 Sol（46.8%），但成本仅为 $0.90/查询 vs $3.03 和 $4.06；GLM 5.2 和 Kimi K3 构成质量–成本 Pareto 前沿。
- **最难用例仍未解决**：Screening & Discovery 和 Sector, Industry & Macro 在所有系统中均为最难，Screening 最佳仅 33%，Sector 最佳仅 39%。
- **推理 effort 增益边际递减**：提高推理强度通常提升达标率，但成本上升更快，且部分模型在高 effort 下出现回落。
- **轨迹复杂性高**：工具调用存在普遍的三阶段结构（信息收集 → 中间综合 → 答案准备）；并行策略差异极大（每轮工具数 1.00~5.86），但高表现模型的最终 token 预算和延迟却接近。
- **参数知识直接取 URL 是失败模式**：部分模型绕过搜索直接访问已知来源，导致 URL 错误率显著升高，造成 token 浪费和上下文污染。

## 7. 优点

- **专家深度参与**：数据由前买方分析师、卖方研究员、投行专家通过四阶段流水线构建，质量有保障。
- **评分细粒度且可解释**：每个 rubric 独立、二元、可溯源，通过宏平均达标率打分，同时支持“必备 rubrics”子集分析。
- **难度标定严谨**：用 BT 模型、多维度成对判断、置信度加权、子采样和位置交换测试验证难度分数，并显示与人工解题时间正相关。
- **全面覆盖投资工作流**：六个用例覆盖从数据抽取到开放式筛选和宏观分析的完整链条，较此前基准有明显扩展。
- **统一评测框架**：限制公共数据、统一工具调用限制和时间预算（200 次调用、300 秒），并在质量之外同时报告成本与延迟，便于实践参考。
- **行为分析深入**：轨迹分析揭示工具使用模式、并行度、URL 来源等，对改进 Agent 系统有启发。
- **开放共享**：数据集和评分代码公开，利于后续研究复现和扩展。

## 8. 不足与局限

- **时间局限性**：每条查询绑定固定日期，未来模型可能从参数记忆而非实际检索和工具使用中作答，削弱基准所测能力。论文提出需周期性重新标注。
- **主观用例偏差**：Screening 等用例本身允许多种合理答案，若系统答案组织方式与 rubrics 不同，可能被低估；论文认为大量不相关 ruby 对的统计平均可缓解此问题，但仍无法完全消除。
- **LLM 裁判的固有缺陷**：虽采用三裁判多数投票和提示约束，但数值近似、单位换算、句子含义等裁判误判风险依然存在；位置交换翻转率在低置信度判断上相对较高。
- **成本估算不完全**：仅覆盖 agentic LLM 的 API 费用，未计入搜索、市场数据、索引存储等外部成本，可能影响跨 harness 成本比较的公平性。
- **样本数量有限**：220 条查询在用例细分下数量偏小（如 Screening 仅 17 条），细粒度统计稳健性受限。
- **数据范围限制**：评测限于公开数据源，而真实专业投资研究常用付费数据库；这可能低估了在商业工具支持下的系统表现。
- **工程配置依赖**：FA-v2 harness 的默认参数（温度、reasoning effort、tool 限制）会影响结果，不同 API 默认值可能造成不公平；论文也未提供复现所需的具体超参细节之外的完整信息。
