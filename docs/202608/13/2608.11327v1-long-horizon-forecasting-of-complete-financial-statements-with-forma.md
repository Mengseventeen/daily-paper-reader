## 摘要
在预测财务报表时，专业训练优于通用规模。据我们所知，此前没有工作联合预测超过一年的完整财务报表，然而在贴现现金流估值中，大部分企业价值位于该窗口之后。我们发布了ProForma-20Q，一个可复现的基准，用于预测匿名企业未来1-20个季度的78个报表行项目，输入为过去的报表和行业代码，评分采用变化空间R²。在此基础上，Forma——一种将报表读取为（账户、季度、数值）元组集合的Transformer，并最大化掩码元组高斯似然——击败了我们测试的所有竞争对手：经典机器学习、链式梯度提升、零样本时间序列基础模型以及前沿大型语言模型。其领先优势随预测期限延长而扩大，而这正是估值最需要准确性的地方，且其高斯预测区间从不覆盖不足。Forma的预测几乎满足会计恒等式；精确的一致性可以在无统计显著准确性损失的情况下恢复。其元组接口支持无需重新训练的情景分析，我们表明，固定未来收入路径能锐化报表其余部分的预测。

## Abstract
Specialist training beats generalist scale when forecasting financial statements. To our knowledge, no prior work jointly forecasts complete financial statements beyond one year, yet in a discounted-cash-flow valuation most firm value sits past that window. We release ProForma-20Q, a reproducible benchmark for forecasting 78 statement line items 1-20 quarters ahead, for anonymized firms, from past statements and an industry code, scored by change-space $R^2$. On it, Forma, a transformer that reads statements as sets of (account, quarter, value) tuples and maximizes a masked-tuple Gaussian likelihood, beats every competitor we field: classical machine learning, chained gradient boosting, a zero-shot time-series foundation model, and frontier large language models. Its lead widens with horizon, where valuation needs accuracy most, and its Gaussian predictive intervals never under-cover. Forma's forecasts nearly satisfy accounting identities; exact coherence is recoverable at no statistically significant accuracy cost. Its tuple interface supports scenario analysis without retraining, and we show that pinning future revenue paths sharpens the rest of the statement.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题核心**：目前学术界的财务预测研究大多只针对单一指标（如盈余）进行一年以内的点预测，**没有工作能够联合预测完整财务报表（三大报表）超过一年的长期表现**。
- **经济动机**：在贴现现金流（DCF）估值中，企业价值的大部分位于一年之后的现金流入，尤其是终值（terminal value）部分。而终值的可信度依赖于完整、自洽的多年期预测报表（利润表、资产负债表、现金流量表），这需要利润率、再投资、融资等维度在报表间保持一致。
- **数据挑战**：财务报表数据天然稀疏，平均每个公司-季度仅披露78个行项目中的64个，完整披露的不到2%；同时数据包含刚性的会计恒等式与软性的经济状态结构（如竞争优势、财务约束）。
- **核心论点**：**针对任务特化的专业模型（约0.9M参数的Transformer）在完整报表预测上显著优于通用大模型（LLM、基础时序模型）**，并且在长周期上优势扩大。

### 2. 方法论

#### 2.1 ProForma-20Q 基准任务
- **预测目标**：78个财务报表行项目（34个资产负债表、18个利润表、20个现金流量表项目，外加6个派生项目），在1-20个季度（5年）的期限内。
- **输入**：12个季度的历史报表（仅报告过的项目），加上行业代码（Fama-French 48）。
- **标准化管线**：
  1. 按公司规模平减（总负债+股东权益绝对值）；
  2. 使用 asinh 变换处理重尾分布；
  3. 按（项目，季度）进行时间序列上的横截面标准化；
  4. 对输入截断至 |x|≤6。
- **评分指标**：变化空间 R²（Change-space R²），避免模型通过重复当前水平获得虚假的高分；R² 20–40% 在多年期即属强表现。

#### 2.2 Forma 架构
- **元组集表示**：将报表建模为 (账户, 季度, 数值) 的三元组集合，缺失项目不产生 token（无需插补），未报告的历史项目天然缺席。
- **Token 编码**：账户嵌入 + 季度正弦位置编码 + 数值投影（掩码 token 使用学习到的掩码向量）。
- **Transformer 编码器**：4层、d_model=128、4注意力头，约0.9M参数，对集合进行注意力运算（类似 Set Transformer），加上行业token和规模token。
- **训练目标**：掩码元组高斯似然（Gaussian 负对数似然，β-NLL 损失，β=0.5），输出每个预测项目的均值μ和异方差方差σ²。使用五种子等权混合作为预测分布。
- **两种掩码策略**：
  - **身份感知分组掩码**：当掩码触及完整会计恒等式组时，至少掩盖组内两个成员，避免模型只学会恒等式的代数运算而非经济规律；
  - **钉住未来掩码**：一半训练样本暴露约5%的未来真实值，使模型学会条件预测，支持情景分析。
- **直接多周期预测**：单次前向传播同时输出1-20季度所有项目的预测，而不是逐步递归推断。

### 3. 实验设计

#### 3.1 数据集与基准
- **数据来源**：Compustat 季度美国申报文件（1970–2024），排除金融企业（SIC 6000-6999）。
- **样本规模**：32,851家公司，1,173,598个公司-季度；训练 1971–2001，验证 2002–2009，测试 2010–2024。
- **数据门槛**：输入需要12个季度历史报表；目标季度按分割边界清除（purged），防止信息泄漏；匿名化处理，不含公司身份。
- **基准发布**：完整管线+配置+评估代码以开源形式发布（可通过 WRDS 一条命令复现）。

#### 3.2 对比方法
| 类别 | 模型 |
|---|---|
| 经典 ML | Elastic Net、随机森林、含线性与大型两种前馈神经网络（FFNN，双侧异方差头） |
| 链式模型 | 重新实现的 Geertsema et al. [15] 链式梯度提升机（GBM），L1/L2两种损失 |
| 基础时序模型 | Chronos-2（零样本，多变量分组，输出原生分位数） |
| 大语言模型 | Claude Opus 4.8、GPT-5.5、Claude Sonnet 5（零样本直接生成预测，两种提示词方案取最优） |
| 简单基线 | 季节随机游走、Fade/AR(1) 池化回归 |
| **本文模型** | **Forma（高斯/拉普拉斯头，五种子混合）** |

#### 3.3 评估足迹
- 全样本（327.2M cells）用于主要比较；
- Geertsema 共同足迹（109.1M cells）用于与链式GBM比较；
- LLM共同足迹（2.15M cells，约2,103个来源）用于与大模型比较——各模型团队在同一子集上重新评分，避免多重交集过度缩减样本。

### 4. 资源与算力

- 文中明确说明：**Forma 每个种子在单张 NVIDIA A100-SXM GPU 上训练约16.5小时**；五种子完整运行成本约**120美元**的按需云计算费用；模型参数量约942K，检查点约11MB。
- LLM 比较的推理成本约为每个来源 0.12–0.26 美元，而 Forma 推理成本可忽略。

### 5. 实验数量与充分性

- **覆盖面广**：实验覆盖 3 条评分轨迹（平方误差R²、绝对误差MAE、分布密度NLL/CRPS/覆盖率），多个共同足迹（3个），固定收入路径的条件预测实验，会计一致性的调和实验。
- **显著性测试**：使用 Diebold–Mariano 检验，按日历季度聚类、Newey-West HAC标准误、HLN小样本修正，显著性标注清晰。
- **公平性考量**：
  - 每个模型都在同一信息集上训练/提示，统一评分；
  - 通用模型（LLM）在测试期数据可能已出现在预训练语料中，这一偏差利于通用模型，但Forma仍胜出；
  - 使用共同脚印避免样本选择偏差。
- **充分性评价**：实验设计周详，涵盖了模型的点预测、分布预测、会计一致性、情景分析等多个维度。主要可补充之处在于：(a) 未做跨国家/地区推广；(b) 未对Forma进行详尽的超参数敏感性分析；(c) 未评估不同历史长度（如6季度/24季度）的输入窗口影响。

### 6. 主要结论与发现

1. **Forma 全面胜出**：在全样本上，Forma 的 R²=28.9%，显著优于随机森林（27.2%）、弹性网络（25.8%）和 FFNN（25.3%/24.7%），差异在1%水平显著。
2. **领先优势随预测周期扩大**：h=1 时随机森林略优（39.8% vs 39.0%），h=2 持平，h=3 起 Forma 领先并持续扩大，到 h=20 时领先 3.2 个百分点以上（0.225 vs 0.193）。这与估值需求的方向一致（越长周期越重要）。
3. **对通用模型的完胜**：最佳 LLM（Opus 4.8）R²=18.6%，远低于 Forma 的 29.9%，差距从 h=1 的5.5pp 扩大到 h=20 的15.9pp。所有目的训练的模型（除AR(1)外）均优于所有 LLM。Chronos-2 仅优于随机游走。
4. **分布预测可靠性**：五种子高斯混合的中心区间从未欠覆盖（如名义90%对应实际93.7%覆盖率），PIT呈中心偏厚（保守而非过锐），长期末端偏保守——对终值使用有利。
5. **会计一致性近似满足**：未受约束时，Forma 中位绝对违规为身份总规模的3.7%；**方差加权调和**可将违规降至0且 R² 无统计显著损失（下降3.8pp，DM t=-1.4），而等权调和则灾难性失败（R²=-5.51）。
6. **情景分析可行**：钉住真实收入路径（oracle experiment）后，其余项目的 R² 从30.5%提升至34.8%，MAE 从0.409降至0.383；收益随预测周期扩大（h=20时+7.4pp）。
7. **核心机制**：模型优势来自**条件均值回归**——识别取决于报表其余部分的、项目特定的回归速度，而非单纯模型容量。更大的无监督FFNN反而落后，说明架构与数据/任务的匹配比参数数量更重要。

### 7. 优点

- **任务定位精准**：填补了"完整报表×长期预测"的空白，与DCF估值中的实际需求对齐。
- **表示设计优雅**：元组集表示天然处理缺失值，无需插补，避免完整案例选择偏差；身份感知掩码引导模型学习经济规律而非会计代数。
- **分布输出完整**：异方差高斯头+五种子混合提供完整预测分布（NLL/CRPS/覆盖率），而非仅点预测。
- **情景分析与决策支持**：钉住未来掩码使模型支持无需重训练的条件预测，服务估值分析中的情景模拟。
- **严谨的评估体系**：变化空间R²、共同样本足迹、日历季度聚类的DM检验、多个评分维度（点预测与分布预测），统计推断规范。
- **可复现性**：基准和模型代码均开源，管线可复现（需WRDS访问）；对LLM的prompt原文完整披露在附录中。

### 8. 不足与局限

- **数据范围限制**：仅覆盖美国上市公司季度申报；结论不直接适用于其他国家、私有企业或其他报告频率。
- **幸存者偏差**：长期预测必然以存活公司为条件——比较是公平的（所有模型在同一细胞上评分），但绝对技能水平仅描述存活样本，不刻画全样本。
- **特征不完整**：模型未使用股票市场数据、分析师预测等信息；只考虑开箱即用的通用模型，未测试微调后的LLM。
- **数据不可再分发**：底层 Compustat 数据受许可保护，其他研究机构无WRDS访问则无法复现精确实验环境。
- **LLM 比较的偏差方向**：LLM的预训练数据包含测试期报表，理论上利于LLM，但形式胜出使该结论更稳健；然而两个提示词arm运行在同一个2,103来源子集上，样本量有限。
- **会计一致性未完全内化**：模型自身输出已接近一致，但需要在原始美元空间事后调和才能实现精确一致；文中也指出调和比较与未调和模型之间的比较不对称。
- **未建模交叉账户协方差**：方差加权调和通过delta方法映射美元空间，但不考虑跨账户协方差。
- **泛化边界**：作者声明范围限于78个行项目、1-20季度、美国季度申报，未验证更细粒度（如月度）或不同项目集上的表现。
