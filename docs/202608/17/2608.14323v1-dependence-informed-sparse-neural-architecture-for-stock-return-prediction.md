## 摘要
使用神经网络进行股票收益预测通常需要对深度和隐藏层宽度做出选择，而这些选择难以与金融解释联系起来。我们研究了一种替代方案：使用最大滤波团森林（MFCF）估计企业特征之间的依赖性，然后将其团结构映射到同调神经网络（HNN）。MFCF的最大团大小K是控制架构复杂性的唯一参数，且具有清晰的图论意义：它限制了每个最大团中的特征数量，从而限制了网络能够表示的最高交互阶数。滤波图随后在训练前固定了神经网络的深度、层宽度和稀疏连接，取代了单独选择的深度和宽度序列。我们使用94个企业特征，将两种HNN变体应用于1987年至2016年美国股票超额收益的年度样本外预测。HNN模型在汇总预测准确性上与三层隐藏层基准相当，在横截面排序上更准确，并且使用的参数比具有相同诱导层宽度的全连接网络少约80倍。两项结构性消融实验表明，稀疏连接和特征的分组估计都对排序优势有所贡献，并且在多重检验校正后，这两种效应仍然显著。这些发现表明，HNN提供了一种实用且可解释的方式，将企业特征之间的估计依赖性纳入神经架构设计。

## Abstract
Using neural networks for stock return prediction typically requires choices about depth and hidden-layer width that are difficult to connect to financial interpretation. We study an alternative: estimate dependence among firm characteristics with a Maximally Filtered Clique Forest (MFCF), then map its clique structure to a Homological Neural Network (HNN). The MFCF maximum clique size K is the only parameter controlling architectural complexity, and it has a clear graphical meaning: it bounds the number of characteristics in each maximal clique and hence the highest interaction order the network can represent. The filtered graph then fixes the neural network's depth, layer widths, and sparse connections before training, in place of a separately chosen depth and width sequence. We apply two HNN variants to annual out-of-sample forecasts of U.S. stock excess returns from 1987 to 2016 using 94 firm characteristics. The HNN models match a three-hidden-layer benchmark on pooled predictive accuracy, rank the cross-section more accurately, and use roughly 80 times fewer parameters than a fully connected network with the same induced layer widths. Two structural ablations indicate that both the sparse connectivity and the estimated grouping of characteristics contribute to the ranking advantage, and both effects remain significant after correcting for multiple testing. These findings show that HNNs offer a practical and interpretable way to incorporate estimated dependence among firm characteristics into neural architecture design.

## 1. 论文的核心问题与整体含义

传统机器学习方法（尤其是多层感知机，MLP）在股票收益预测中表现出色，但研究者需要预先指定网络的深度和隐藏层宽度，而这些架构超参数通常通过验证集搜索确定，缺乏直接的金融解释。本文试图回答一个核心问题：**能否用公司特征之间的经验依赖结构来自动确定神经网络架构，从而替代手工选择的深度与宽度序列？**

论文提出了一种基于依赖信息的稀疏神经网络架构——同调神经网络（Homological Neural Network, HNN），通过两步实现这一目标：
1. **估计特征依赖**：使用最大滤波团森林（MFCF）从训练数据中提取特征间的依赖结构，得到一组有界大小的团；
2. **映射为网络架构**：将团结构直接映射为神经网络的深度、层宽、连接方式，形成稀疏网络。

其核心含义在于：**网络架构不再是先验设定的容量选择，而是从数据中“长出来”的结构**，每个单元代表一个具体的特征子集，具有图论与金融上的双重可解释性。

## 2. 方法论

### 2.1 整体框架
- 设股票 $i$ 在月份 $t$ 有 $p$ 个特征 $x_{i,t} \in \mathbb{R}^p$，预测目标为下月超额收益 $y^e_{i,t+1}$。
- 模型形式为 $\hat{y}^e_{i,t+1} = f_{\theta,A}(x_{i,t})$，其中 $A$ 是由 MFCF 确定的架构，$\theta$ 是训练参数。

### 2.2 MFCF 依赖图构建
- 输入为特征间的**绝对 Pearson 相关矩阵** $D_{ab} = |\text{corr}(X_a, X_b)|$（特征已按截面排名，故等价于秩相关，对异常值与单调变换稳健）。
- MFCF 逐步将特征节点加入图，每一步选择一个可允许的分离集 $S$，以如下评分函数决定最优连接：

$$G(v, S) = \sum_{u \in S} D^2_{vu}$$

- 产生一族**最大团** $\mathcal{C}$，且每个团的大小不超过上限 $K$（最大团大小），**$K$ 是控制网络复杂性的唯一结构参数**，决定了网络能表示的最高交互阶数。

### 2.3 HNN 架构映射
- 图的所有团及其子集按大小分层：第 $k$ 层包含所有大小为 $k$ 的保留子集 $\mathcal{H}^{(k)}$，层宽 $n_k = |\mathcal{H}^{(k)}|$。
- 层间连接遵循**集合包含关系**：大小为 $k$ 的单元只接收其 $k-1$ 阶子集传来的输入，从而每个单元恰好有 $k$ 条入边。
- 激活计算（$k=2,\dots,K^\star$，$K^\star$ 为实际最大团大小）：

$$\hat{h}^{(k)}_{i,t} = \text{ReLU}\left(\text{LN}_k\left(W^{(k)} h^{(k-1)}_{i,t} + b^{(k)}\right)\right)$$

- **多尺度读出**：每一层先压缩为标量 $r^{(k)}_{i,t} = (a^{(k)})^\top h^{(k)}_{i,t} + c^{(k)}$，再线性组合为最终预测：

$$\hat{y}^e_{i,t+1} = \sum_{k=2}^{K^\star} \beta_k r^{(k)}_{i,t} + d$$

这使得每个交互阶数都直接通向输出，避免被更深层覆盖。

### 2.4 复杂度分析
- 稀疏参数数 $P_{\text{sparse}} = \sum_{k=2}^{K^\star} k n_k$（线性于层宽）。
- 同宽全连接参数数 $P_{\text{dense}} = \sum_{k=2}^{K^\star} n_{k-1} n_k$（乘积增长）。

### 2.5 变体与对照
| 模型 | 说明 |
|---|---|
| HNN (marginal) | 仅用全部训练样本估计依赖矩阵构建 MFCF |
| HNN (m-s) | 按训练收益中位数分成两个子样本分别估计 MFCF，再取团并集 |
| HNN (input-shuffled) | 将特征随机排列到 HNN (marginal) 的输入节点，拓扑与容量不变 |
| MLP-HNN | 保持 HNN (marginal) 的深度和层宽不变，但改为全连接、末层读出 |

## 6. 主要结论与发现

1. **预测精度平手**：HNN (marginal) 和 HNN (m-s) 的池化 $R^2_{\text{oos}}$ 分别为 0.509% 与 0.511%，略高于 NN3 的 0.475%，但差异不显著（$p = 0.796$）。
2. **截面排序更优**：HNN (marginal) 在所有模型中取得最高 Pearson IC（0.0642）和最高 EW 多空价差（3.95%/月），显著优于 NN3（$p = 0.002$，Holm 调整后 $p = 0.034$）。
3. **参数效率极高**：相比同宽度全连接 MLP-HNN（约 168 万个参数），HNN (marginal) 仅需约 2.1 万个参数，**约 80 倍缩减**，同时排序表现更好。
4. **两个消融均有贡献**：
   - 随机打乱特征-节点对齐使 Pearson IC 显著下降（调整后 $p = 0.003$），说明**特征与团结构的对齐本身携带信息**；
   - 替换为全连接架构后排序表现下滑，说明**稀疏连接是有效的归纳偏置**。
5. **经济稳健性**：25 bps 单边成本下 HNN (marginal) 的月净 EW 价差为 3.34%（年化 Sharpe 2.28），盈亏平衡成本约 159 bps；排序优势在成本扣除后依然保持。
6. **时效性差异**：HNN 在 1987–1996 领先，NN3 在 1997–2006 领先，后十年（2007–2016）两者均出现负 $R^2$ 但多空价差仍为正；资产加权下 NN3 反而更优，暗示优势集中于小盘股。

## 7. 优点

- **可解释的架构设计**：网络深度、宽度、连接均由数据依赖图决定，每个神经元对应明确的特征组合，可直接读取模型表达的交互结构，解决深度学习中“黑箱架构选择”问题。
- **极简的超参空间**：架构搜索从“深度 × 宽度 × 连接”退化为单一结构参数 $K$ + 学习率，大幅降低调参成本。
- **参数高效**：线性稀疏连接将参数数从乘积级降为求和级，并实际改善了排序表现。
- **消融实验设计精巧**：input-shuffled 控制在容量不变的前提下隔离“特征-图对齐”效应，MLP-HNN 控制深度宽度隔离连接模式效应，归因清晰。
- **统计方法严谨**：采用配对检验、HAC 标准误、Holm 多重比较校正，结论可靠性较强。
- **经济视角完整**：不仅看预测误差，还评估排序能力、组合收益、换手率与交易成本敏感性，连接了统计意义和经济意义。

## 8. 不足与局限

- **特征集受限**：未复现 GKX 的完整 920 输入规格（缺少行业虚拟变量和宏观交互项），因此是一个“受控架构对比”而非完整的 GKX 复现；结论在更大特征集上是否成立未验证。
- **依赖度量简单**：MFCF 只使用绝对 Pearson 相关（秩相关），无法捕捉非线性依赖与条件依赖；论文承认可替换为互信息等更丰富度量但未实证。
- **资产加权表现反转**：AW 价差下 NN3（2.44%）优于 HNN (marginal)（1.99%），说明 HNN 的排序优势可能主要由小盘股驱动，其普遍性存疑。
- **后期表现不佳**：2007–2016 年所有神经网络模型的 $R^2$ 均为负，虽然多空价差仍为正，但该期间模型对收益水平的预测力弱化，长期稳健性有待考察。
- **交易成本模型简化**：仅按统一线性成本 + 换手率估算，未考虑个股买卖价差差异、融券费用、市场冲击与容量限制。
- **超参选择仍有手动成分**：$K$ 的候选值网格仍需研究者设定，学习率也是如此；尽管搜索空间大幅缩减，但某种程度的模型选择依然存在。
- **未报告训练成本细节**：缺少 GPU 配置、计算时间等资源信息，难以评估该方法在大规模部署时的实际计算代价。
