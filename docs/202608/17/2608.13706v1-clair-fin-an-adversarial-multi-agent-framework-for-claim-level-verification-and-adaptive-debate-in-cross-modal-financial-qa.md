## 摘要
针对检索增强和多智能体流水线中幻觉的现有防御仍然是不完整的：尽管模态之间存在分歧，证据仍被信任；辩论验证的是汇总报告而非单个声明；并且这种验证仅在起草之后进行，使得智能体间错误直到最终文本才被发现。为弥补这一差距，我们提出了CLAIR-Fin，一个九智能体框架，它将每个问题分解为原子声明，并维护在类型化的金融声明分类账中。每个声明通过非对称证据权威来解决，该机制根据声明类型来调节证据信任度，而非将所有模态视为同等可靠；通过监管链验证，在起草与对抗性审查之间的交接点检查基础依据，而非仅在流水线出口检查；通过自适应反驳循环，将存在争议的声明路由至对抗性辩论，其深度随辩论结果而扩展；以及一个终端蕴含审计，并配以持续幻觉风险指数，以区分已通过审查的声明与从未被质疑的声明。我们在BB-FinQA-X上评估CLAIR-Fin，这是一个基于孟加拉银行年报材料构建的500题跨模态金融评估集，按查询类型、格式和难度进行分层。相对于单次检索增强生成基线，它将忠实度从0.780提升至0.889，同时在证据不足时对5.4%的问题选择弃权而非强行给出无依据的回应，并且在忠实度上超越了更强的检索策略基线（如HyDE和Graph-RAG，其忠实度≤0.874）。

## Abstract
Existing defenses against hallucination in retrieval-augmented and multi-agent pipelines remain partial: evidence is trusted despite modality disagreement, debate verifies an aggregate report rather than individual claims, and such verification occurs only after drafting, leaving inter-agent errors undetected until the final text. To close this gap, we present CLAIR-Fin, a nine-agent framework that decomposes each question into atomic claims maintained in a typed Financial Claim Ledger. Each claim is resolved through Asymmetric Evidence Authority, which conditions evidence trust on claim type rather than treating all modalities as equally reliable; Chain-of-Custody Verification, which checks grounding at the hand-off between drafting and adversarial review rather than only at the pipeline's exit; an Adaptive Rebuttal Cycle, which routes contested claims through adversarial debate whose depth scales with what that debate finds; and a terminal entailment audit paired with a continuous Hallucination Risk Index that distinguishes claims that passed scrutiny from claims never contested. We evaluate CLAIR-Fin on BB-FinQA-X, a 500-question cross-modal financial evaluation set built from Bangladesh Bank Annual Report material, stratified by query type, format, and difficulty. Relative to a single-pass retrieval-augmented generation baseline, it raises faithfulness ($0.780 \rightarrow 0.889$) while abstaining on 5.4% of questions when evidence is insufficient rather than forcing an unsupported response, and it exceeds stronger retrieval-strategy baselines such as HyDE and Graph-RAG on faithfulness ($\leq 0.874$).

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：金融机构日益依赖 LLM 回答长篇幅、多模态（文本、表格、图表）的财务报告问题。同一事实可能以不同形式出现在同一文档中，且彼此存在差异（例如表格精确值 vs. 图表的近似读数），误读一个财年标签或把图表近似值当作精确值，都可能改变结论。
- **现有方法的三个关键缺陷**：
  1. **证据信任未考虑模态分歧**：检索到的证据一旦被引用即被信任，表格单元格与图表近似值被当作可互换的同等证据，缺乏裁决机制；
  2. **辩论验证粒度太粗**：对抗式辩论作用于整体报告层面，而非单个声明，分歧未被标记，辩论深度固定且不随争议程度调整；
  3. **验证时机过晚**：声明级验证（如 Chain-of-Verification、FinGround）只在起草完成后进行，智能体间错误直到最终文本才被发现。
- **研究目标**：构建一个在**声明级别**、**交接节点前置**、且附带**连续风险信号**的防幻觉框架，使模型在证据不足时能够明确弃权而非强行作答。

## 二、方法论：核心思想、关键技术细节与流程

### 2.1 总体架构
CLAIR-Fin 是一个**九智能体**框架，包含八个阶段，以类型化**金融声明账本（FCL）**为核心数据结构——一个有向多图，记录声明、证据、约束检查及 SUPPORTS / SAME_AS / VIOLATES_CONSTRAINT 三类边关系，并贯穿整个问答生命周期。

### 2.2 关键技术组件

| 组件 | 作用 |
|---|---|
| **声明分解**（Planner-Orchestrator） | 将问题分解为 1–8 个原子声明，每个声明带类型 τi ∈ {FACT_NUMERIC, FACT_TREND, CAUSE_ATTRIBUTION, RATIO_IDENTITY}，决定证据加权方式 |
| **三路证据提取**（叙事/表格/视觉智能体） | 表格证据按（行、列、值、单位）接地；图表证据以**带对冲的近似表述**保留；计算器产生 tool_derived 派生量 |
| **非对称证据权威（AEA）** | 按声明类型对模态赋权（表 1），如 FACT_NUMERIC 信任表格（0.55）> 派生（0.30）> 文本（0.10）> 图表（0.05）；覆盖度 A(ci) 决定是否进入辩论 |
| **链式保管验证（CoCV）** | 在起草与对抗性审查的**交接处**检查接地性（entails 且 γ≥0.5），失败则做一次有界修复；防止归因漂移传播到后续推理 |
| **自适应反驳循环（ARC）** | 仅对覆盖度不足的声明启动辩论；存在 high 严重度攻击且轮次未达上限（ρmax=2）时继续反驳；辩论深度随争议程度缩放而非固定 |
| **终审与幻觉风险指数（HRI）** | 按 AEA 权重取最大模态置信度生成裁决（Supported / StronglySupported / InsufficientEvidence），HRI 综合蕴含置信度、权威分数、修复次数与高严重度攻击数，提供连续风险信号 |
| **选择性弃权** | 每个声明独立判定；所有声明均未通过时整体弃权；部分通过时输出部分答案并附带引用 |

### 2.3 核心公式（文字说明）
- **检索重排**：候选池由向量搜索取得后，按 L2 距离归一化相似度（权重 0.65）与词项重叠（权重 0.35）加权重排。
- **声明覆盖度**：A(ci) = 该声明对应各模态权威权重之和；A(ci) < 0.75 则升级至对抗性验证，否则快速通道直达终审。
- **终审裁决**：胜出模态 m* = argmax [w(τ,m)·conf_m(ci)]；强度 s(ci) = w(τ,m*)·conf_m*(ci)。s ≥ 0.5 判为 StronglySupported。
- **HRI** = 0.40(1−γ) + 0.25(1−s) + 0.20(修复次数) + 0.15(高严重度攻击数)，裁剪至 [0,1]。

## 三、实验设计

- **数据集**：**BB-FinQA-X**——基于孟加拉银行年报（2024–2025）手工构建的 500 题跨模态金融问答集，按**查询类型**（6类）、**呈现格式**（6类）、**难度**（易/中/难）三维分层。
- **评估指标**：RAGAS 四指标（忠实度、答案相关性、上下文精确率/召回率）+ 精确正确率、答案覆盖率、HRI 校准（与正确性的相关性）、辩论利用率、AEA 影响率；另有 2 名外部银行领域专家对全部 500 个答案进行 6 维度盲评（5 分制，加权 Cohen's κ）。
- **对比基线**：Vanilla RAG（单次检索生成）、HyDE RAG、Hierarchical RAG、Graph-RAG。
- **消融实验**：逐一移除 AEA、CoCV、ARC、终审蕴含审计，共 4 组，全部在相同代码路径上通过修改单一配置值实现。

## 六、主要结论与发现

- **整体效果**：相对于 Vanilla RAG，忠实度从 0.780 提升至 0.889（↑0.109），上下文精确率 0.700→0.816，上下文召回率 0.840→0.897；超越 HyDE（0.874）与 Graph-RAG（0.832）。
- **弃权行为**：5.4% 的问题在证据不足时明确弃权（27/500），而非强行生成无依据答案；人类评分的弃权恰当性均分约 4.0/5，κ=0.84。
- **各机制的边际贡献排序**：移除 ARC 造成的下降最大（忠实度 0.889→0.770，精确正确率 0.592→0.524，覆盖率 0.946→0.896）；移除终审审计（→0.845）比移除 CoCV（→0.857）影响更大，二者互补而非可替换；移除 AEA 影响最小（→0.883）但 AEA 影响率达 0.515（约半数裁决因非对称加权而改变胜出模态）。
- **格式敏感性**：Text+Table 最易（忠实度 0.915），Chart Only 最难（0.850）；Matched-pair 检验确认格式本身导致差异（Table Only 优于 Text Only +0.030；Text+Chart 优于 Chart Only +0.025）。
- **查询类型**：Fact Extraction 最高（0.920），Evidence Retrieval 与 Multi-hop Reasoning 最低（≈0.839–0.840）。
- **HRI 校准**：与正确性负相关（r=−0.072），方向正确、幅度小，表明是一个边际补充信号而非二值门控的冗余。

## 七、优点

- **机制设计的针对性强**：声明级分解使每个阶段的接地性检查可精确定位到句子级错误；AEA 让跨模态分歧的裁决依据可陈述、可审计的设计先验。
- **验证前置**：CoCV 在起草与对抗审查的交接处检查，而非仅在流水线出口，符合防幻觉应尽早的直觉。
- **自适应辩论深度**：辩论只在证据覆盖不足时启动、深度随争议程度调整，避免固定轮次在简单声明上浪费算力。
- **负责任地弃权**：弃权是一等公民行为（5.4% 触发率），且被人类专家评定为恰当。
- **透明性与可审计性**：权威裁决记录（Authority Docket）对比非对称与等权反事实，使 AEA 的偏差影响可审计而非隐形。
- **实验方法学诚实**：明确承认固定权重是设计选择而非学习所得；局限性披露详尽。

## 八、不足与局限

- **数据覆盖狭窄**：仅孟加拉银行单一机构、单一语言（英语）、单一央行报告惯例，不保证向其他机构、财年惯例或语言泛化。
- **固定设计参数**：AEA 权重表、HRI 权重、升级阈值（0.75）与蕴含通过阈值（0.5）均为手工指定，未经过学习或人类标注校准，是一个合理工作点而非最优值。
- **LLM-as-judge 循环风险**：自动指标（RAGAS 等）与框架自身的蕴含检查共享 LLM 评判方法论，系统性偏差无法通过双检查点独立捕获。
- **跨模态链接启发式粗糙**：依赖表格行标签与其他节点的文本子串匹配，会漏掉语义等价引用，也可能产生偶合误连。
- **预算上限**：辩论最多 2 轮、接地修复最多 1 次，需要更多争论的声明不被完全解决。
- **消融覆盖不足**：未测试多机制组合相互作用；w/o ARC 仅对比"有/无辩论"，未对比"自适应分配 vs. 固定轮次均匀应用"。
- **成本未量化**：未报告各机制引入的额外 LLM 调用数与墙钟延迟，准确率—成本权衡未量化。
- **未测鲁棒性**：未评估对对抗性问题、分布外问题、噪声或损坏 PDF 的鲁棒性；未扩展到多轮对话或部署场景。
