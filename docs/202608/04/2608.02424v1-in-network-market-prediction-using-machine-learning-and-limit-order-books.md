## 摘要
机器学习正在显著改变算法交易，但对快速执行速度的需求仍然存在。尽管这两个方面都旨在提升盈利能力，但在降低交易延迟的同时嵌入先进的机器学习技术却是一个显著的挑战。采用网络内机器学习，即将推理卸载到可编程网络设备上，在这种权衡中提供了一种微妙的平衡。在本文中，我们提出了LOBIN，一种利用网络内机器学习基于高频市场数据流进行市场预测的解决方案。LOBIN能够直接在可编程交换机中构建限价订单簿并执行推理。与基于服务器的基准相比，LOBIN不仅以更高的吞吐量预测未来股票价格变动，而且还保持了稳健的机器学习性能。与纳斯达克订单匹配服务器基准相比，它实现了超过10%的延迟降低，并提供微秒级延迟。此外，通过采用集成交换机和服务器的混合部署方法，LOBIN的机器学习性能可以进一步提升。我们的评估表明，在所有被评估股票的数据流中，采用混合部署使得约45%的流量和总潜在交易价值的38%在交换机内处理，无需服务器干预，从而降低延迟，同时确保预测错误率的平均变化相对于仅使用服务器的基准保持在约3%左右。

## Abstract
Machine learning is significantly transforming algorithmic trading, yet the requirement for rapid execution speeds persists. While both aspects aim to boost profitability, embedding advanced machine-learning techniques with reduced trading latency presents a notable challenge. Adopting in-network machine learning, which involves offloading inference to programmable network devices, offers a delicate equilibrium in this trade-off. In this paper, we present LOBIN, a solution that utilizes machine learning within the network for market prediction based on high-frequency market data feeds. LOBIN is adept at constructing limit order books and performing inference directly within programmable switches. When compared to server-based benchmarks, LOBIN not only predicts future stock price movements with higher throughput but also maintains robust machine learning performance. It achieves over a 10% reduction in latency compared to the NASDAQ order-matching server benchmark and delivers microsecond-level latency. Furthermore, the machine learning performance of LOBIN can be further enhanced through the adoption of a hybrid deployment approach that integrates both the switch and the servers. Our evaluation demonstrates that among all data feeds of evaluated stocks, the application of hybrid deployment results in approximately 45% of the traffic and 38\% of the total potential transaction value being processed within switches without server intervention, reducing latency while ensuring that the average change in error rate of predictions remains at around 3% relative to benchmarks based solely on server use.

## 1. 核心问题与整体含义

- **研究背景**：算法交易尤其是高频交易（HFT）对微秒级延迟有极致追求，而机器学习模型虽能提升预测能力，但模型复杂度增加会带来计算延迟，二者存在根本矛盾。
- **现有方案的局限**：传统方案在服务器上完成限价订单簿（LOB）构建与推理，延迟高；使用FPGA、ASIC、GPU等加速虽降低延迟，但未解决“在网络内部”进行智能处理的问题。
- **研究动机**：网络内机器学习（In-network ML）可将预训练模型部署在可编程交换机数据平面上，在数据经过网络时直接完成特征提取与推理，从而绕过服务器往返，兼顾低延迟和高吞吐。
- **核心问题**：能否在可编程交换机中实时维护限价订单簿（LOB）并执行机器学习推理，以进行高频市场预测？由此提出**LOBIN**（Limit Order Books In Network）原型系统。
- **总体含义**：LOBIN是首个将网络内机器学习用于时间敏感型金融交易场景的研究，展示了在保持与服务器相近预测性能的同时，将延迟降低10%以上并达到微秒级，为构建新一代超低延迟交易系统提供了可行路径。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：将LOB构建/更新、特征提取、ML推理全部下沉到可编程数据平面（交换机），让市场数据报文在交换机内部完成从“原始订单消息”到“交易决策/分类结果”的端到端处理；并可通过混合部署，将低置信度样本转发给服务器上的大模型进一步处理。

- **系统工作流程**：
  1. 在服务器上，用历史MBO（Market-by-Order）数据训练ML模型（离线阶段）；
  2. 将训练好的模型映射为P4可执行代码，并生成LOB构建与特征提取相关P4逻辑；
  3. 将P4程序加载到可编程交换机（Tofino/BMv2），同时通过控制平面下发表项；
  4. 交换机在线处理MBO流：更新LOB → 计算中间价 → 提取特征 → 执行ML推理 → 输出预测结果；
  5. 混合部署时，若交换机推理置信度低于阈值，则把报文转发到服务器上的大模型。

- **LOB更新算法（以买单为例）**：
  - 通用算法（BMv2，Algorithm 1）：维护三个寄存器——最低卖价位置、最高买价位置、各价格水平数量。若新买单价格低于最低卖价，则直接加入对应价格水平并更新最高买价；否则从最低卖价到订单价格逐层匹配成交量，直到成交量耗尽或遍历完，再更新最佳买卖价。
  - Tofino硬件算法（Algorithm 2）：由于Tofino不支持循环、比较消耗大量stage、寄存器读写限制，改为“扁平并行”设计——用循环展开（loop unrolling）同时处理多个价格水平；每个价格水平根据与订单价格、剩余数量的比较，进入四种场景之一（不足、正好、有余、新订单剩余量驻留），从而并行更新每个level，再通过**重循环（recirculation）**完成寄存器读写。

- **特征与标签**：
  - 特征：LOB中每个价格水平的数量（BMv2和服务器用10个水平；Tofino用3个水平）+ 中间价；
  - 标签：未来100个tick后中间价变动方向（上涨/下跌/不变），使用平滑标签法与SMOTE过采样处理类别不平衡。

- **ML模型**：KM、KNN、决策树（DT）、随机森林（RF）、XGBoost；服务器模型大小不受限，交换机模型受硬件限制（如DT深度≤4、树集成≤4棵树）。

- **混合部署策略**：交换机上的小模型仅对置信度高的样本直接分类，低置信度样本发往服务器，兼顾性能与准确率。

## 6. 主要结论与发现

- **可行性**：LOBIN成功在可编程交换机上实时构建、更新LOB并执行ML推理，证明网络内机器学习可用于高频市场预测。
- **ML性能**：
  - BMv2与服务器基准接近：平均准确率仅损失4.39%，F1损失6.47%；
  - Tofino因资源限制损失更大：平均F1约为服务器基准的63.5%，准确率约71.6%；但对FANG股票，树模型准确率损失<1%；
  - Tofino 2（更大资源）可比Tofino多支持两个LOB特征，性能有提升；
  - 树集成方法在网络上表现相对稳定、性能损失较小。
- **网络性能**：
  - 微秒级延迟，与简单转发接近；
  - 相比NASDAQ订单匹配服务器基准，延迟降低>10%；
  - 吞吐量达3.2Tbps（两个Tofino管道，各1.6Tbps）。
- **混合部署价值**：
  - 对FANG，全部在交换机处理时错误率仅增加<3%，平均延迟降低~9.5%（vs NASDAQ基准）；
  - 对EXC（阈值0.98）和AZN（阈值0.96），错误率增加<5%，同时交换机直接处理48.12%和27.81%的订单；
  - 综合三只股票，约45%的流量和38%的交易价值（约19.7亿美元/51.3亿美元）可在交换机内处理，平均错误率变化约3%。

## 7. 优点

- **开创新领域**：首次将网络内机器学习应用于高频交易的市场预测，填补领域空白。
- **复杂数据结构上板**：成功将LOB这种有状态、多价格水平的复杂数据结构实现在P4可编程交换机中，并解决了Tofino无循环、寄存器访问受限等硬件难题。

- **扩展数据规模与市场环境**：建议使用多日、多只股票、覆盖不同波动率与市场状态（如开盘/收盘、新闻冲击、闪崩）的数据进行验证，提升结论的泛化性和鲁棒性。

- **卸载更多金融计算任务**：将LOBIN框架推广到盘口失衡、波动率估计、套利检测等更多低延迟金融计算任务，构建通用金融网络内计算中间件。
