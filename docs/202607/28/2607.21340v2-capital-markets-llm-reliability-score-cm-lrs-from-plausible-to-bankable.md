## 摘要
在资本市场工作流程中，问题很少是大语言模型能否生成流畅的草稿，而是草稿是否值得信赖：在手持文件的情况下，是否能在对手方或监管机构面前站得住脚。现有方法解决了部分差距：开放域问答基准测试奖励表面准确性，金融基准测试（FinanceBench、FinQA、ConvFinQA）推进了基于文档和数值的问答，但评估停留在问答层面，而非从业人员所辩护的工作流输出。我们引入了CM-LRS，即资本市场LLM可靠性评分，在工作流输出层面对七个维度进行评估：事实准确性、证据可追溯性、数值一致性、工作流完整性、来源纪律、决策有用性以及可审查性/可审计性。每个维度按照受监管环境中审查员使用的信号标准进行0-5分评分；总分可根据工作流进行调整。我们在五个工作流程（DCM交易条款提取、先例检索、发行人概况综合、M&A交易可比较推理、ECM交易条款提取）上展示了CM-LRS，这些工作流程基于公开的SEC EDGAR文件、公开的英国收购公告以及虚构的合成补充材料，使用三个模型家族的四个独立LLM评审员对四个模型进行了评分。三个发现。第一，前沿闭源模型在四个评审员平均CM-LRS上的得分差距在0.22分以内（Sonnet 4.6 = 4.31，Opus 4.7 = 4.30，GPT-5.5 = 4.09）；所有四个评审员都将开放权重基线模型（Llama 3.3 70B = 3.15）排在最后。第二，这一差距主要集中在检索（2.23）和综合（2.15）上，而非提取（0.84）。第三，决策有用性在所有维度中显示出最大的跨模型离散度（发行人概况方面为4.0分），并且评审员间一致性最高（平均r = 0.52）。看似合理性很廉价。值得信赖才是标准。

## Abstract
In capital-markets workflows the question is rarely whether a large language model can produce a fluent draft, but whether the draft is bankable: defensible in front of a counter-party or a regulator, with the documents in hand. Existing methods address parts of that gap: open-domain QA benchmarks reward surface accuracy, and finance benchmarks (FinanceBench, FinQA, ConvFinQA) advance document-grounded and numerical QA but evaluate at the question-answer layer rather than the workflow outputs practitioners defend.   We introduce CM-LRS, a Capital Markets LLM Reliability Score, evaluating outputs at the workflow-output layer across seven dimensions: factual accuracy, evidence traceability, numerical consistency, workflow completeness, source discipline, decision usefulness, and reviewability/auditability. Each is scored 0-5 against a rubric anchored on signals reviewers in regulated settings use; the aggregate is tunable to the workflow.   We demonstrate CM-LRS on five workflows (DCM transaction-terms extraction, precedent retrieval, issuer profile synthesis, M&A transaction-comparable reasoning, ECM transaction-terms extraction) over public SEC EDGAR filings, a public UK takeover release, and fictional synthetic supplements, scoring four models against four independent LLM judges spanning three model families.   Three findings. First, the frontier closed-source models cluster within 0.22 points on four-judge averaged CM-LRS (Sonnet 4.6 = 4.31, Opus 4.7 = 4.30, GPT-5.5 = 4.09); all four judges place the open-weights baseline (Llama 3.3 70B = 3.15) last. Second, that gap concentrates on retrieval (2.23) and synthesis (2.15), not extraction (0.84). Third, Decision Usefulness shows the widest cross-model dispersion of any dimension (4.0 points on issuer profiling) and top-tier inter-judge agreement (mean r = 0.52).   Plausibility is cheap. Bankability is the bar.

### 论文核心问题与整体含义（研究动机和背景）

- **核心问题**：在受监管的资本市场工作流（如投行交易条款提取、发行人概况撰写、可比交易分析等）中，LLM 生成的输出即使表面流畅，也难以直接投入实际业务使用。现有评估方法（如 QA 基准、金融 NLP 基准）仅在问答对层面衡量准确性，无法捕捉到输出在审查者（银行家、分析师、合规人员）面前是否“可银行化”（bankable）——即每项主张能否追溯到可验证的源文档、数字是否一致、工作流是否完整、模型是否添加了源文档不支持的内容、输出是否对下游决策有用、审查者能否在数分钟内验证完毕。

- **含义**：需要一种新的评估体系，在工作流输出层而非问答对层评估 LLM 的可靠性，填补“看似合理”与“值得信赖”之间的差距。作者将此视为高监管环境部署 LLM 的关键前置条件。

### 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：提出 **CM-LRS（Capital Markets LLM Reliability Score）**，一个多维度评分框架，从七个可靠性维度对 LLM 的工作流输出打分（0-5 分），并允许根据工作流类型调整各维度的权重。

- **七维度定义**：
  1. **事实准确性（D1）**：实质性主张是否与源文档一致。
  2. **证据可追溯性（D2）**：每个主张是否关联到可验证的源文本段落。
  3. **数值一致性（D3）**：数字提取、转换和比较是否正确，导出值是否与输入吻合。
  4. **工作流完整性（D4）**：是否完成了任务要求的每一个步骤。
  5. **来源纪律（D5）**：是否避免了无依据的假设、编造、填充和过度推断。
  6. **决策有用性（D6）**：输出能否直接用于推动工作流，而非需要大量返工。
  7. **可审查性与可审计性（D7）**：输出的出处（输入、检索步骤、确定性计算、模型调用）是否可被人类审查和重现。

- **评分公式**：聚合分数为加权和：  
  `CM-LRS = Σ_{i=1}^7 w_i · s_i`，其中 `s_i ∈ [0,5]`，`w_i ≥ 0`，且 `Σ w_i = 1`。  
  提供了按工作流类别（提取、检索、综合、比较推理、起草）的默认权重表（表 3）。

- **部署就绪阈值建议**：对于高风险受监管工作流，建议 `CM-LRS ≥ 4.0` 且无单个维度低于 3 分，任何维度得 0 或 1 分则直接淘汰。

- **评审者间协议控制**：采用四个独立 LLM 评审员（Sonnet 4.6、GPT-5.5、Haiku 4.5、Gemini 2.5 Pro）进行交叉验证，覆盖三个模型家族，控制自偏和家族偏。

### 优点

- **工作流层评估**：直接对应实际部署场景，填补了 QA 层评估与监管审查需求之间的鸿沟。
- **多维度精细评分**：七维度覆盖事实性、可追溯性、一致性、完整性、纪律性、有用性和可审计性，每个维度有明确的 0-5 锚点。
- **跨评审员验证**：使用四个来自三个模型家族的独立 LLM 评审员，系统性地控制自偏和家族偏，提高了评分的鲁棒性。
- **完全可复现**：所有提示、评分标准、原始输出均以 CC BY 4.0 许可公开，附带确定性验证脚本。
- **实用的部署阈值**：建议 CM-LRS ≥ 4.0 且无维度低于 3，提供了一个可操作的门控标准。

### 不足与局限

- **自动化评审替代人类**：虽然使用四个 LLM 评审员，但仍未引入人类银行家/合规官的实际评分，人类与 LLM 评审协议之间的一致性是未来重点。
- **工作流覆盖不完整**：未包含“起草”类工作流（如备忘录撰写、推介材料起草），也未覆盖嵌套多文档的复杂任务。
- **文档截断偏差**：所有文档被截断至 6000 token，仅测试封面和前言内容，未暴露深层条款（如埋在 200 页后的契约或风险因素）的失败模式。
- **单轮评估，非代理模式**：实际部署中常见工具调用、多步检索等代理模式，本评估未涵盖。
- **模型面板有限**：未包括 Gemini、Mistral、Qwen、DeepSeek 等模型，且开源仅测试了 Llama 3.3 70B（70B 参数），可能不代表更大或更小的模型。
- **权重未经验证**：默认工作流权重为从业者直觉设定，未通过实际审查决策回归得到实证校准。
- **静态基准**：演示文件固定于发布时间点，随模型能力进步可能失去区分力。
- **未覆盖合规性方面**：不评估 MNPI 处理、信息隔离墙、市场滥用等监管合规义务，通过 CM-LRS 并不等同于合规通过。
